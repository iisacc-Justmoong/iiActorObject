# MakeHuman CC0 data

This directory contains unmodified graphical data from the official
[MakeHuman repository](https://github.com/makehumancommunity/makehuman), pinned to
`a8bc2d54ff0ac92e78ff71431b1023eda42bf482`.

The base mesh, default skeleton, skin weights, modeling modifier data and 472
additive body/face targets are CC0 1.0 Universal. `LICENSE.md` distinguishes assets
from AGPL application code. `LICENSE.ASSETS.md` is the original CC0 statement.
No MakeHuman application code, Python modules, shaders or UI assets are included.

`UPSTREAM-SHA256.json` maps every copied file to its original path, byte count and
SHA-256 digest. Paths are shortened; contents are unchanged. `catalog.json` is an
iiActorObject-authored deterministic index, not an upstream file.

Selected families: armslegs, buttocks, cheek, chin, ears, eyebrows, eyes, forehead,
head, hip, mouth, neck, nose, pelvis, stomach and torso. Macro-detail interpolation,
expression units, asymmetry, clothing, hair and textures are outside this snapshot.
The body uses the authored `body` group; hidden helper and joint faces remain in
source topology for stable IDs and anchors. This package does not establish CC5,
Unreal or MetaHuman application compatibility.
