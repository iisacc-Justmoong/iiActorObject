# iiActorObjectVisualCodec contributor instructions

- This project is an application-side composition of separately selected SDKs.
- Preserve the parent actor module's FBX image limits, ownership, tests, and ABI.
- Keep source headers next to their implementation and build outputs under the parent module's `build/`.
- Keep the human documentation and its agent JSON projection synchronized.
- Do not run user-facing applications; synthetic contract tests are allowed.
