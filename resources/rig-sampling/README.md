# Rig sampling test resources

`adult.fbx` and `child.fbx` are frozen test fixtures generated by this project from the CC0 MakeHuman resources and earlier native fitting and authoring work. They contain 163 bones, five meshes and 43,474 source points each. They are used for native SDK numerical tests; they are not production MetaHuman assets and do not establish application compatibility.

- `adult.fbx`: SHA-256 `12db89354a9fd2ffd4abc1cd2c88b7db104f567ff69cf1d8b9a75d68e2eb5c57`.
- `child.fbx`: SHA-256 `003875cec34bc8f9790800658a8b12ad0635923656501b6eb3f9e20040951f4f`.

The original generated copies are preserved as earlier build evidence. The input assets and their licenses and provenance are in `resources/MakeHuman*`.
