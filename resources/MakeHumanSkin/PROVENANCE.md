# MakeHuman CC0 skin assets

These unmodified `.mhmat` descriptions and PNG skin images are from the official [MakeHuman system assets pack](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html), whose publisher identifies these assets as CC0. Original material descriptions contain the CC0 statement. `UPSTREAM-SHA256.json` records the archive URL, size, ETag, entry offsets, CRC-32, byte counts and SHA-256 hashes. Entries were retrieved using exact HTTP ranges; a whole-archive digest was not obtained. `catalog.json` is an iiActorObject-authored selection index, not an upstream file. Source preset names do not classify or infer a person. Original LitSphere shaders, subsurface-scattering parameters and other material effects are not reproduced.
