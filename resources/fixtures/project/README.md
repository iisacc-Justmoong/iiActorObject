# Legacy native project fixtures

`v1.ii3dproject` is an original iiActorObject test asset, generated by the version 1
writer before surface bindings were added. It contains a quad, an unused point,
the `height` template target, and one control-point correction layer. It is used
to verify that current readers preserve and continue older editing sessions.
It contains no third-party application data or executable code.

`v2.ii3dproject` was generated by the version 2 writer from the same original
test scene before layer point masks were introduced. Current readers must retain
both older sessions, their parameters, and their correction layers.

`v3.ii3dproject` was generated by the unmodified version 3 library before joint
scale corrections and parent overrides were added. It also includes a nonuniform
point mask `{1, .5, .25, 0, .5}` on its one correction layer. The version 4 reader
must preserve that mask and continue the same `height` parameter edits.
