# 인체 부속 제거와 선택 이력 검증 기록

이 문서는 당시 제거 기능을 검사한 이력이다. 이후 부속 삽입과 추가 후 교체는 [추가 검증 기록](HumanAccessoryAdditionVerification-20261029.md)에서 다룬다.

## 범위

[인체 부속 계약](HumanAccessories.md)에 따라 같은 엔진의 대체 템플릿으로 기존 부속을 제거한다. 남은 메시 순서는 유지하며, 본체 편집 계층·마스크·이름 있는 점 선택과 생성 타깃·관절 앵커·표면 연결·접지 및 자동 맞춤의 메시 인덱스를 다시 연결한다. 삭제된 메시가 다른 남은 표면의 입력이거나 타깃·앵커·접지·자동 맞춤에 필요하면 거부한다. NSCharacter는 카탈로그 의미를 검사하고 본체 편집기를 호출한다.

MakeHuman의 CC0 인체에서 몸과 눈썹을 각각 조형하고 피부 PNG와 눈썹 점 선택을 적용한 뒤, 중간에 있는 여성 의상 메시를 제거했다. 눈썹의 메시 번호가 3에서 2로 바뀌어도 위치·선택 가중치·몸 위치·피부 이미지는 유지됐다. 저장·새 엔진 복원 후 undo는 눈썹 번호를 3으로, redo는 2로 되돌렸고 이후 얼굴 폭 조절도 수행했다. 별도 인체에서 편집된 의상의 제거는 기본적으로 거부하며 명시적으로 허용한 제거는 undo로 원래 의상을 복원했다. 네 부속을 한 번에 제거하고 undo하는 경우도 검사했다.

820개 타깃을 가진 매크로 인체에서도 나이·키·질량을 지정한 채 의상을 제거하고, 이후 나이·키를 다시 바꾼 결과의 한 몸 원본 점을 원래 템플릿의 같은 체형과 비교했다. 기존 발 기준점은 보존됐다. 새로 드러난 점이 발 기준 평면보다 아래에 있을 수 있다는 [기존 접지 계약](HumanMorphology.md)은 그대로 적용된다.

## 본체 이력과 형식

축소된 본체 테스트에서는 중간 추종 메시를 제거하면서 뒤쪽 메시의 조형, 점 마스크와 이름 있는 선택을 보존했다. 삭제 대상에 편집이나 선택이 있으면 기본 옵션에서 거부하고, `discardRemovedEdits=true`로 현재 상태에서 제거하면 선택 이름은 빈 상태로 남는다. 저장·복원한 이력의 undo로 삭제된 선택이 돌아온다. 이력이 잘려 매핑의 이전 상태가 사라진 경우에도 시작 상태가 복원된다. 다른 엔진, 중복 슬롯, 본체 슬롯 삭제와 남은 표면이 의존하는 슬롯의 삭제는 상태를 바꾸지 않고 거부한다.

점 선택 인덱스가 바뀐 이력은 프로젝트 버전 33으로 보관한다. 복원은 대응이 남은 메시 순서와 원본 점 연결을 보존하고 선택 이름·가중치를 바꾸지 않았는지 검사한다. CRC를 다시 계산한 손상 프로젝트에 범위 밖 인덱스를 넣어도 복원은 거부되며 새 엔진에 임시 자원이 남지 않는 것을 확인했다. 기존 버전 1~8 fixture와 버전 32 접지 저장·복원, 버전 21·23 형식 검사를 포함한 회귀도 통과했다. 다른 자료에 버전 33이 필요하지 않으면 기존 버전 선택을 유지한다.

몸의 가림을 바꿀 때 삼각형 프레임 추종은 남은 원본 폴리곤·코너를 찾아 새 렌더 삼각형 번호로 옮긴다. 표면 교체와 제거 양쪽에서 살아 있는 부착점의 위치를 검사했고, 가려지는 삼각형 자체에 부착된 표면은 변경을 거부했다. 표면 원본 점 기반 연결은 원래 점 ID를 그대로 사용한다.

## 독립 파일 판독

의상을 제거한 인체를 GLB와 FBX로 내보내 별도 Python 판독기로 읽었다. 출력 메시 네 개에서 제거된 의상은 없었고, 몸의 숨김 폴리곤은 0개, 표시 삼각형은 26,756개였다. 남은 네 메시의 스킨 속성, 본 연결 및 제어점별 가중치 합을 검사했다. 의상의 재질·이미지는 현재 에셋에서 정리하지 않으므로 두 출력에 사용되지 않는 의상 이미지도 남았다. 파일 구조 검사는 외부 애플리케이션의 가져오기나 시각 품질을 증명하지 않는다.

## 빌드와 검사

- macOS arm64 C++23 Release: 본체 표면 교체·제거·접지와 인체 편집·독립 형식 검사 18/18, 매크로 인체 교체·제거 1/1 통과. `build/glb-import-ninja/human-surface-remove-final.xml`, `human-accessory-remove-grounded.xml`.
- NSCharacter 제외 본체 전용 Release: 표면 교체·제거, 접지, 프로젝트와 계층 회귀 52/52 통과. `build/core-tangent-ninja/human-surface-remove-final.xml`.
- NSCharacter 포함 Debug ASan·UBSan: 표면 교체·제거, 인체 제거와 독립 형식 검사 8/8 통과. 누수 검출은 비활성화했다. `build/glb-import-full-asan/human-surface-remove-asan.xml`.
- `build/`에 별도 설치한 본체 전용 소비자 1/1과 NSCharacter 포함 소비자 2/2가 공개 API, 제거된 선택 이력 저장·복원과 인체 부속 제거를 검사했다. 사용자 설치본은 바꾸지 않았다. 각 소비자 빌드의 `human-surface-removal.xml`.
- 변경된 선택·표면·프로젝트·NSCharacter 구현은 Emscripten C++23 구문 검사를 통과했다. macOS 빌드의 생성된 설정을 사용했으며 SDK 전체 WebAssembly 링크나 실행은 검사하지 않았다.
- macOS 라이브러리 직접 링크는 C++ 표준 라이브러리와 시스템 라이브러리만 포함했다. Qt 직접 링크는 확인되지 않았다.

## 남은 범위

인체 부속의 편집 중 추가, 슬롯 순서 변경, 제거와 다른 부속 교체의 단일 작업 결합, 기존 부속 조형의 대체 형상 전사 및 사용되지 않는 재질·이미지 정리는 남아 있다. 천·머리카락 물리, 겹친 의상, 자세별 충돌, 제작용 피부와 머리카락 표현도 별도 작업이다. 제거 전 스냅샷에 연결된 리그는 필요에 따라 다시 연결해야 한다.

사용자 지시에 따라 CC5·Blender·Unreal 및 사용자용 앱을 실행하지 않았다. 앱 간 실제 가져오기와 렌더링, 제작용 MetaHuman 수준의 품질, 전체 캐릭터 생성·상세 편집 목표는 이 기록으로 입증되지 않으며 계속 진행 중이다.
