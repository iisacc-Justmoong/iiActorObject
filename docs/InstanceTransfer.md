# 편집 전후 액터 상태 이전

## 목적과 사용

`transferObject3DInstance`는 원본 에셋과 그 에셋의 `iiCharacter`, 새 에셋을 받아 새 액터를 준비한다. 원본 에셋·액터와 새 에셋은 수정하지 않는다. 포즈, 현재 모프 값, 재생 중인 클립과 시간·재생 속도·반복 방식·일시 정지 상태, 액터 변환·이름·태그와 보존되는 메시 컴포넌트 설정을 옮긴다. 본체 iiActorObject의 기능이며 NSCharacter는 본체 에셋 참조를 제공한다.

```cpp
#include <iiActorObject/Object3DInstanceTransfer.h>

auto previous = editor.asset()->object();
// active는 previous에서 만든 액터, rigs는 같은 편집기를 따르는 리그 세트이다.
// 이 사이에 editor를 편집하거나 undo/redo한다.
auto next = transferObject3DEditorInstance(previous, *active, rigs);
auto currentRigs = rigs.rigs();
// 호스트가 자신의 장면에서 active를 next.actor로 교체한다.
```

`transferObject3DEditorInstance`는 리그 세트가 마지막으로 연결된 에셋과 원본이 같은지 확인한 후 액터를 먼저 준비하고, 세트 전체를 현재 편집 에셋에 재연결한다. 액터 준비나 어느 리그의 재연결이 실패해도 새 액터를 반환하지 않으며 이전 액터와 리그 연결은 유지한다. 성공 시 `rigsRebound`가 실제 리그 재연결 여부를 나타낸다. 인스턴스와 리그 세트에 각각 지정한 관절 ID 정책이 모두 통과해야 한다. 리그 세트 없이 사용하거나 별도로 조정하려면 `transferObject3DInstance`를 호출한다.

새 액터는 `Created` 상태다. 기존 액터의 실행 상태를 자동으로 종료하거나 새 액터의 생명 주기를 시작하지 않는다. 호스트가 장면 교체·수명·이벤트와 렌더러 연결을 관리한다. 이전 액터의 ID를 재사용하지 않으며, 검사 실패로 새 액터 생성이 취소되어도 내부 액터 ID가 소비될 수 있다. 이전 리그의 결과는 이전 에셋에 속하므로, [편집 리그 참조](EditorRigFollow.md)로 새 에셋에 재연결한 뒤 적용한다.

이전과 편집·리그 갱신은 같은 호스트 스레드에서 수행해야 한다. 이전 중 원본 액터나 편집기를 다른 스레드에서 바꾸지 않는다.

## 포즈와 애니메이션

기본 `BindRelative`는 같은 부모 구조의 각 본에 대해 이전 기준에서의 위치 차이, 회전 차이, 스케일 비율을 새 기준에 적용한다. 애니메이션의 각 키에도 같은 변환을 적용하고 스칼라 곡선은 유지한다. 현 시점에 별도로 적용된 포즈를 보존한 뒤, 다음 재생부터는 새 클립의 기존 키 보간 규칙을 따른다. 부모가 바뀌면 이 방식은 거부한다. 두 스냅샷의 관절 이름·의미·ID는 [리그 재연결과 같은 규칙](EditorRigFollow.md)으로 확인하며, 이름 없는 ID의 안정성을 호스트가 보장하는 경우에만 `TrustStableIndices`를 선택한다.

기준은 두 에셋의 골격 바인드 포즈다. 원본 액터가 에셋의 작성용 기준 포즈로 초기화되었더라도 그 값은 현재 포즈로 이전된다. 대상 에셋의 작성용 기준 포즈로 현재 포즈를 초기화하지 않는다.

변환은 로컬 채널에서 위치 `새 기준 + (현재 - 이전 기준)`, 회전 `새 기준 × 이전 기준의 역회전 × 현재`, 축별 스케일 `새 기준 × 현재 / 이전 기준`이다. 위치 차이를 본 길이에 비례해 재조정하는 모션 리타기팅은 수행하지 않는다.

`PreserveWorld`는 부모가 바뀐 경우를 포함해 각 본의 현재 오브젝트 공간 행렬을 유지한다. 새 로컬이 TRS로 표현될 수 없거나 역행렬이 불가능하면 거부한다. 기준 골격 또는 부모가 달라진 상태에서 실행 중인 클립을 이 모드로 자동 변환하지는 않는다. 호스트가 명시적으로 `discardAnimation`을 선택한 경우에는 현재 월드 포즈만 이전한다. 이 모드는 본 행렬을 보존하며, 바뀐 스킨 바인드에 따른 메시 변형까지 동일하다는 뜻은 아니다.

인스턴스별 변형 바인드는 기준 골격과 부모가 같은 경우 보존한다. 그렇지 않으면 기본적으로 거부하며, `discardIncompatibleDeformationBind`를 선택한 경우에만 제외한다. 기존 클립이 그 바인드를 요구한다면 해당 클립도 명시적으로 제외해야 한다. `discardAnimation`은 클립만 제외하며 속도 설정은 보존한다. 액터에 기록된 이전 애니메이션 오류는 새 액터로 옮기지 않고 `omittedAnimationError`로 보고한다.

`AnimationPlayer`에 실제로 연결된 단일 클립이 대상이다. 외부 호스트가 별도로 보유한 클립 목록·모프 곡선 바인딩·타임라인 UI 상태는 저장하거나 이전하지 않는다. 제어값은 호출자가 보관하고 리그에 다시 전달한다.

## 메시와 안전한 실패

메시 이름으로 유지되는 에셋 컴포넌트를 대응하고, 그 안의 모프는 이름으로 대응한다. 새 메시와 새 모프는 대상 에셋의 기본값으로 시작한다. 원본 액터에서 제거된 컴포넌트는 새 액터에서도 생략한다. 사라진 메시나 모프에 0이 아닌 모프 값이 있으면 기본적으로 거부하며 `discardMissingMorphs`를 명시하면 제외 수를 보고한다.

현재 LOD의 인스턴스별 이중 사원수 혼합 가중치는 렌더 점 대응이 확인될 때만 옮긴다. 원본 토폴로지가 있으면 원본·layout·렌더 연결을 비교한다. 토폴로지가 없는 별도 에셋은 순서별 위치가 같고 중복 위치가 없어야 한다. 같은 에셋의 동일 메시는 직접 대응한다. 확인할 수 없으면 기본적으로 거부하며 `discardIncompatibleSkinOverrides`는 이를 명시적으로 제외한다. 에셋의 기본 스키닝 프로필은 대상 에셋의 것을 사용한다.

원본 에셋에 속하지 않는 사용자 컴포넌트, 중복 메시 컴포넌트 또는 사용자 정의 하위 클래스는 기본적으로 거부한다. `discardExtraComponents`를 선택하면 이를 제외한다. 유지되는 메시의 부모가 제외되면 새 루트에 붙이되 기존 월드 변환을 TRS로 보존할 수 없는 경우에는 거부한다. `Object3DInstanceTransferReport`는 유지·추가·제거·생략한 메시, 복사·제외한 모프와 스킨 override, 제외한 컴포넌트와 재연결 수, 클립·변형 바인드 처리를 나타낸다.

이전 결과는 호스트에 새 액터를 반환하는 일회성 준비 단계이며, 자동 장면 교체나 사용자 정의 컴포넌트 복제는 제공하지 않는다. [검증 기록](InstanceTransferVerification-20261029.md)에 검사한 범위와 남은 사항을 기록한다.
