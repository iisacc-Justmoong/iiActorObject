# 편집 가능한 GLB 자산 가져오기

`importObject3DGlb(engine.reference(), bytes, options)`는 메모리의 GLB 2.0을 읽어 메시, 골격, 가중치, 모프, UV, 머티리얼과 PNG를 iiActorObject 본체가 소유하는 새 에셋으로 만든다. 입력은 임시 자료로 검증한 뒤 마지막에만 엔진에 게시한다. 실패하면 부분 에셋을 게시하지 않는다. `NSCharacter::importGlb`는 이 에셋의 비소유 캐릭터 뷰와 같은 관절 대응·경고를 반환한다. 선택적 [GLB 외부 작업 정보](GlbExternalEdits.md)와 점 복원 상태도 반환하며 자동 삼각형 대응에 사용할 수 있다. 엔진 소멸 또는 명시적 제거는 참조를 만료시킨다.

가져오기 예산과 정책만 사용하는 코드는 `Object3DGlbImportOptions.h`, 외부 이미지 해석기를 구현하는 코드는 `GlbImageResolver.h`를 직접 포함할 수 있다. 기존 `Object3DInterchange.h`도 두 인터페이스를 제공한다. 이미지 해석기와 요청 자료의 수명은 호출자가 관리한다.

내부 접근자 판독기는 좌표·UV·스킨·모프·점 ID·삼각형의 타입과 예산을 검사한다. 별도 정점 묶음 조립기는 판독 결과와 비소유 스킨 대응으로 임시 토폴로지를 만든다. 조립 중 오류가 생기면 가져오기 경로가 임시 자료와 작업량을 폐기하며, 최종 에셋은 게시하지 않는다.

프리미티브별 삼각형은 모든 인덱스와 스킨 점을 검사한 뒤 면·재질·법선 상태를 함께 추가한다. 공유 정점과 원본 점의 재사용 및 키 예산은 별도 색인에서 관리하고, 탄젠트 메모 경고와 원본 탄젠트의 불변 스냅샷도 각각 분리된 처리기가 담당한다.

## 장면과 스킨

- 기본 또는 첫 번째 장면의 메시 노드를 사용한다. 장면이 없으면 부모 없는 노드를 사용하고 경고한다. 여러 장면은 선택된 하나만 가져오며 경고한다.
- 여러 스킨의 공통 관절은 같은 본체 골격의 본으로 합치고, 스킨별로 서로 다른 관절 집합도 함께 보관한다. 각 스킨의 `skin.joints` 순서는 `skinMappings`에 보존한다. 기존 `sourceJointToBone`은 첫 메시에서 사용된 스킨의 대응이다. 본체 루트가 필요하면 인공 루트를 추가한다. 각 본 사이에 있는 비본 노드의 변환은 골격 로컬 변환에 합성하며, shear 등 본체 TRS로 표현할 수 없는 관절은 거부한다.
- glTF 스킨은 메시 노드 대신 관절 전역 변환과 역 바인드를 사용한다. 각 스킨 안에서 `관절 전역 × 역 바인드`가 같은 기준 변환인지 확인하고 해당 스킨의 기준을 메시·모프에 적용한다. 서로 다른 스킨은 다른 기준을 사용할 수 있다. 같은 스킨 안의 기준이 서로 다르거나 본체 TRS로 표현할 수 없는 경우는 거부한다. 스킨이 없는 메시만 있으면 정적 에셋을 만들고, 스킨 메시와 섞이면 자신의 노드 전역 변환을 굽고 가장 가까운 원본 관절에 고정한다. 관절 조상이 없으면 인공 루트에 고정한다. 원래 노드 계층과 정적 분류는 이 단일 에셋에 그대로 남지 않으므로 경고한다. [여러 스킨 계약](GlbMultiSkin.md)을 따른다. 법선은 역전치로 변환하고 반사 변환의 삼각형 와인딩을 보정한다.

## 메시, 이미지와 손실 경계

GLB 입력 내부에서 확인된 JSON 필드 접근·공통 손실 정책은 `Object3DGlbJson`, 머티리얼·텍스처·이미지 해석과 중복 이미지 참조 관리는 `Object3DGlbMaterials`가 담당한다. 노드 계층의 탐색과 좌표 변환은 `Object3DGlbScene`, 스킨·관절 대응과 시맨틱 판독은 `Object3DGlbSkin`, 메시와 토폴로지의 구성은 `Object3DGlbMesh`가 담당한다. `Object3DGlbMeshAttributes`는 프리미티브 속성과 모프 대상의 JSON 판독·검증, 접근자 공유 키, 모프 이름과 기본 가중치만 다루며 버퍼를 읽거나 에셋을 소유하지 않는다. 법선이 누락된 면의 법선과 모프 법선 델타 생성은 `Object3DGlbFlatNormals`가 토폴로지와 작업량 한도를 받아 처리한다. 이 구현들은 가져오기 작업의 자료와 옵션을 빌려 사용하며 공개 API나 에셋 소유권은 바꾸지 않는다. 메시 내부 처리의 남은 분리는 [책임 분리 보고서](ResponsibilitySeparation-20261029.md)에 기록한다.

- 삼각형 인덱스 또는 비인덱스 메시, 위치·법선·탄젠트, 연속된 `TEXCOORD_n`, `JOINTS_n`·`WEIGHTS_n`, 위치·법선·탄젠트 모프와 여러 프리미티브의 머티리얼을 읽는다. glTF의 희소·정규화 접근자와 필수 `KHR_mesh_quantization`을 사용한 지원 정수 형식도 읽는다. 여러 가중치 세트를 임의로 4개나 8개로 자르지 않는다. [원본 탄젠트 계약](GlbAuthoredTangents.md)은 보존·변환·편집 후의 재출력 정책을 정한다.
- 같은 위치·스킨·위치 모프 접근자를 쓰는 프리미티브는 법선·UV·탄젠트가 달라도 원본 점을 공유하고 각 속성 layout은 분리한다. 서로 다른 접근자도 SDK의 [점 식별 정보](GlbPointIdentity.md)가 유효하고 표시 값이 일치하면 원래 제어점으로 다시 연결한다. 식별 정보가 없거나 충돌하면 같은 값으로 추측해 합치지 않고 별도 점으로 보관하며 경고한다. 같은 메시 안에서 UV 세트 수가 다르면 누락된 **사용되지 않는** 좌표를 본체 좌표계의 `(0,0)`으로 채우고 경고한다. 텍스처가 해당 프리미티브에 실제로 없는 UV 세트를 요구하면 가져오기를 거부한다. 내보낸 파일에는 채운 좌표가 포함되므로 원본의 속성 부재 자체를 왕복 보존하는 것은 아니다. GLB 접근자에 남은 원본 정점과 UV·법선 layout 및 사용되지 않는 점은 `MeshTopology`에 남기며, 표시 메시와 삼각형은 파생된다. 원래의 사각형이나 DCC 편집 토폴로지는 GLB에 없는 경우 복원하지 못한다.
- 법선이 없는 프리미티브에는 해당 삼각형마다 분리된 법선과 표시 layout을 만들고 경고한다. 같은 메시의 다른 프리미티브에 제공된 법선은 유지한다. 파일 전체에서 추가 표시 layout은 800만 개를 넘기지 않는다. 공유 원본 점의 ID와 사용되지 않는 점은 유지한다. 모프로 위치가 바뀌면 면별 법선 변화도 계산한다. 법선이 있는 부분과 없는 부분이 혼합된 경우, 없는 부분의 모프 법선 변화는 가져올 때 계산한 명시적 델타로 기록한다. 각 델타는 해당 모프의 값이 1인 끝점의 면 방향을 기준으로 하며, 중간값이나 여러 모프가 함께 작동할 때는 델타를 선형 혼합하고 정규화한다. 이후 표면을 편집하면 필요에 따라 모프 법선을 다시 계산해야 한다. 이름이 없는 모프는 `Target_n`을 생성하며, 중복 이름은 고유화하고 경고한다. 메시 기본 모프 가중치와 노드별 재정의를 본체 자산에 보관하며, 노드의 값이 우선한다. 새 인스턴스는 이 값으로 시작한다. [기본 모프 값 계약](DefaultMorphWeights.md)을 따른다.
- 선택된 메시가 사용하는 PBR 기본색·거칠기·금속도와 PNG 기본색·노멀 텍스처, UV 선택을 지원한다. 사용되지 않는 머티리얼·텍스처·이미지는 가져오지 않으며 개수를 경고한다. `OPAQUE`·`MASK`·`BLEND`, 임계값과 양면 여부는 본체 [재질 표면 설정](MaterialSurface.md)에 보존한다. `GlbImageResolver`를 지정하면 호스트가 이미지 URI를 해석하거나 내장 JPEG 등 다른 형식을 PNG로 변환할 수 있다. 요청의 문자열·바이트 뷰는 호출 중에만 유효하며, 파서가 경로를 직접 열지는 않는다. 출력 PNG의 누적 크기와 해석기 호출 횟수를 제한한다.
- 기존 `importObject3DGlb`는 애니메이션이 있는 입력을 기본적으로 거부하며 `allowDiscardAnimations`를 명시하면 경고와 함께 에셋만 가져온다. 애니메이션도 보존할 때는 아래의 별도 입력 API를 사용한다. 색상 등 지원하지 않는 속성, 지원하지 않는 선택적 확장과 일부 머티리얼·샘플러 의미도 기본적으로 거부한다. `allowDiscardUnsupportedAttributes`를 선택한 경우에만 해당 데이터를 버리고 경고한다. 지원하지 않는 필수 확장과 비삼각형 프리미티브는 계속 거부한다.

`GlbImportOptions`는 입력 바이트·JSON·접근자 예산 외에 노드, 메시, 프리미티브, 원본 정점, 삼각형, 본, 스킨 수와 스킨별 관절 대응의 합, 모프, 모프별 처리 정점 수, 정점당 0이 아닌 가중치 수, 가중치 세트 수, UV, 이미지 및 해석기 호출을 제한한다. 원본 정점 처리 한도는 속성 묶음별 정점 수를 세므로 제어점을 공유하는 서로 다른 layout도 각각 포함한다. 법선 유무가 혼합된 메시에서 모프 법선을 생성할 때는 위치 델타가 있는 모프마다 원본 점 수와 생성된 면 코너 수의 두 배를 합산하고, 파일 전체의 작업량을 `maximumMorphDeltas`로 별도 제한한다. 작업량이 큰 정당한 입력은 이 옵션을 높여야 할 수 있다. 기본 영향 수 상한은 64이며 호출자가 높일 수 있다. 상한을 넘으면 잘라내지 않고 거부한다. 출력 관절 대응은 각 `skin.joints`에서 본체 본 ID로 가는 방향이다. 이름·점 대응과 본체의 소유권을 확인한 뒤 편집기·리그 세션을 연결해야 한다. 혼합 속성 경로의 검사와 한계는 [검증 기록](GlbMixedAttributesVerification-20261029.md)에 정리한다.

## 원본 애니메이션과 자세 샘플

`importObject3DGlbWithAnimations(engine.reference(), bytes)`는 에셋과 원본 애니메이션 채널, 선택된 장면의 노드 대응을 함께 반환한다. `NSCharacter::importGlbWithAnimations`는 같은 데이터를 비소유 캐릭터 뷰와 함께 반환한다. 애니메이션은 본체의 `GlbAnimationSource`가 소유하며 원본 노드 ID, 타깃 경로, 초 단위 키, 출력값과 `LINEAR`·`STEP`·`CUBICSPLINE` 보간을 유지한다. 에셋 입력과 별도인 이미지 해석기 등의 알림은 보존한다. 애니메이션의 임의 `extras`와 채널에서 사용하지 않는 샘플러는 보존하지 않으며 애니메이션 확장은 거부한다. 애니메이션이 참조하는 접근자와 버퍼 뷰의 확장도 압축 데이터를 일반 데이터로 해석하지 않도록 거부한다. 지원하지 않는 필수 GLB 확장은 단독 채널 판독에서도 거부한다. `readGlbAnimationSources`는 에셋을 만들지 않고 채널만 읽는다. 같은 메시가 여러 노드에 인스턴스화되거나 같은 이름의 모프가 여러 메시에서 사용되어도 원본 노드와 출력 메시 번호를 구분한다. 원본 애니메이션의 이름은 중복을 포함해 유지한다.

`GlbAnimationSource::sample`은 각 원본 노드의 채널 값을 반환한다. 위치·스케일·모프는 선형 또는 단계 보간, 회전은 최단 경로 구면 보간, 큐빅은 원본 접선과 키 시간 간격을 사용하는 Hermite 보간이다. 큐빅 회전은 결과를 정규화한다. 각 채널의 첫 키 이전과 마지막 키 이후에는 끝값을 사용하고, 루프를 선택하면 전체 재생 길이로 시간을 감싼다. 원본 정수 정규화 회전·모프 접근자도 디코딩한다. 값은 잘라내지 않는다. 입력 예산 `maximumAnimations`, `maximumChannels`, `maximumSamplers`, `maximumDecodedValues`는 각각 기본 1,024개, 100,000개, 100,000개, 16,000,000개다. 마지막 값은 같은 접근자를 여러 채널에서 사용하면 채널마다 다시 센다.

정적 에셋에 포즈 샘플을 적용할 때는 내부 더미 루트가 원본 관절이 아니므로 기존 루트 포즈를 유지하고 모프만 적용한다.

`sampleGlbAnimationPose(object, nodes, source, seconds)`는 원본 노드의 키와 변환 계층을 조합해 본체 골격의 로컬 자세와 메시·타깃 번호별 모프 값을 계산한다. 비관절 부모의 애니메이션도 자손 관절에 반영한다. 애니메이션이 없는 본 변환 요소는 가져온 원본의 기본 변환을 사용하며, 이미 편집된 인스턴스 자세에 자동으로 합성하지 않는다. 모프는 애니메이션 채널이 있는 메시의 값만 출력한다. 본체 에셋을 소유하는 엔진과 동일한 에셋의 `Pose` 및 메시 컴포넌트 배열을 `applyGlbAnimationPose`에 전달하면 확인된 값을 적용한다. 컴포넌트 배열은 가져온 메시 순서여야 하며, 다른 에셋·골격·인스턴스의 컴포넌트 또는 변경된 변형 바인드를 거부한다. `SkeletalMeshComponent::boundPose()`는 컴포넌트가 사용하는 자세를 비소유 참조로 확인한다. 샘플 계산은 입력 에셋과 인스턴스를 수정하지 않는다. 적용은 샘플과 대상을 먼저 검증한다.

선택하지 않은 장면의 노드가 목표인 애니메이션을 자세로 샘플링하거나, 관절에 고정된 정적 메시의 고정 관계 아래에서 노드가 별도로 움직이는 경우에는 자세 샘플링을 거부한다. 움직이는 관절 행렬이 본체의 TRS로 나타낼 수 없는 shear를 포함하거나 역행렬을 만들 수 없어도 해당 샘플을 거부한다. 원본 채널은 이 경우에도 보존된다. 지원되는 입력은 [클립 변환](GlbAnimationBake.md)으로 메시별 모프 대응과 함께 `AnimationClip`으로 표본화할 수 있다. 원본 큐빅 접선과 DCC 리그의 직접 재출력은 제공하지 않는다. 편집 가능한 원본 DCC 리그, 스킨별 공통 기준으로 표현되지 않는 역 바인드, 비삼각형 도형, 모든 머티리얼·텍스처 확장과 시각 품질은 별도 작업이다. 사용자 지시에 따라 실제 CC5·Blender·Unreal 앱은 검증하지 않는다.
