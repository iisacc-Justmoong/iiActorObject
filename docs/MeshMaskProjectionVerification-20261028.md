# 점 선택 마스크 투영 검증

2026-10-28 macOS arm64에서 [서로 다른 토폴로지의 선택 마스크 투영](MeshMaskProjection.md)을 네이티브 C++ 테스트로 검사했다. CC5·Blender·Unreal 및 다른 사용자용 앱은 실행하지 않았다.

- 기준 정사각형을 두 삼각형, 대상을 중심점을 가진 네 삼각형으로 구성했다. 기준 UV 경계에서 원본 제어점이 여러 렌더 정점으로 분리된 경우에도 원본 선택 가중치를 사용하고, 중심점의 보간값과 미사용 원본 점의 기본 0 값을 확인했다. 옵션을 켜면 미사용 대상 점도 투영한다.
- 작성용 토폴로지가 없는 렌더 전용 메시, 존재하지 않는 기준 선택 행, 한 기준 메시에서 두 대상 메시로의 대응과 대상 행 정렬을 검사했다.
- 결과를 별도 에디터의 이름 있는 선택에 적용하고 undo·redo·프로젝트 내보내기와 복원을 확인했다. 일반 구성에서는 `NSCharacter::CharacterEditor`가 같은 본체 세션을 참조하는지도 확인했다.
- 거리 초과, 잘못된 거리·마스크·메시 인덱스, 중복 대상과 마스크, 빈 대응, 기하·점·질의 예산 초과를 거부하고 기존 에셋·에디터 revision과 선택이 유지되는지 확인했다.

별도의 일반 구성 네이티브 테스트에서 CC0 인체의 렌더 정점 14,517개를 삼각형 중심점으로 재분할해 41,273개로 늘렸다. 높이에 비례하는 선형 시험 마스크를 대상 점 41,273개에 투영했을 때 기대 가중치와의 최대 차이는 `4.44089e-16`, 최대 표면 거리는 `4.60287e-16`이었다. 노드 방문 1,441,373회, 삼각형 검사 659,242회를 사용했다. 같은 형상과 위치에서 수학적으로 선형인 마스크를 사용한 한 시료이며 얼굴·팔 등 의미 영역의 선택 정확도를 증명하지 않는다.

일반과 NSCharacter를 제외한 코어 구성을 빌드하고 각각 CMake 등록 검사 4/4를 통과했다. 두 구성의 테스트 실행 파일에서 다중 메시 사례도 각각 통과했으며, 일반 구성에는 `NSCharacter` 편집 참조 검사가 포함된다. 위의 인체 시료는 공용 전사 구현을 직접 링크한 일반 구성의 별도 테스트로 실행했다. 다중 메시와 인체 사례도 CMake 테스트 정의에 등록했다. 기존 이름 있는 선택 회귀 검사는 일반 6/6, 코어 6/6 통과했다. 일반·코어 별도 스테이징 설치본의 공개 헤더와 라이브러리를 사용하는 소비자 검사는 각각 1/1 통과했다.

두 공유 라이브러리의 동적 의존성은 macOS의 C++ 표준 라이브러리와 시스템 라이브러리이며 Qt 동적 의존성은 보이지 않았다. 사용자 앱 실행 검증 설정은 두 구성 모두 꺼져 있다. 설치 소비자는 `build/`의 스테이징만 사용했으며 `~/.local` 설치본을 바꾸지 않았다.

가중치는 가까운 가시 삼각형의 선형 보간이다. 이 합성 입력은 서로 다른 자세·의복 층·맞닿은 손가락 등의 의미 구분을 입증하지 않으며, 거리 안의 다른 표면이 선택될 수 있다. 기준의 숨은 면은 투영 대상에서 제외된다. 전체 목표의 MetaHuman 수준 외형과 외부 앱 동작을 입증하는 검사는 아니다.
