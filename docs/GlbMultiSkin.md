# GLB 여러 스킨과 정적 메시 가져오기

`importObject3DGlb`는 선택된 장면에서 사용된 모든 스킨의 관절 노드를 모아 하나의 본체 소유 골격을 만든다. 같은 장면 노드를 참조하는 관절은 하나의 본으로 공유하며, 각 스킨의 원본 관절 배열과 스킨 인덱스는 `GlbImportResult::skinMappings`에 남는다. `NSCharacter::importGlb`는 같은 대응표와 본체 에셋을 참조하는 캐릭터 뷰를 반환한다. 여러 스킨일 때 기존 `sourceJointToBone`은 첫 메시에서 사용된 스킨의 대응이다.

관절 ID는 선택된 장면 노드를 너비 우선으로 순회하며 메시가 스킨을 처음 사용하는 순서와 그 스킨의 `joints` 순서로 부여한다. 이미 수집한 관절 노드는 다시 만들지 않는다. 부모는 합쳐진 관절 집합에서 가장 가까운 원본 조상이다. 루트가 여럿이거나 첫 관절이 유일한 루트가 아니면 본체의 0번에 인공 루트를 둔다. 장면의 관절 밖 노드 변환은 해당 본의 로컬 변환에 합성한다. 각 스킨의 관절은 선택된 장면에 공통 루트를 가져야 하고, 선택적 `skeleton`을 지정하면 모든 관절의 조상이어야 한다. 깊은 계층을 반복 탐색하지 않도록 장면의 깊이 우선 구간으로 검사한다.

각 스킨 `s`에서 기준 자세의 관절 전역 행렬 `J_i`와 역 바인드 `I_i`에 대해 `J_i × I_i = B_s`가 같은지 허용 오차 내에서 확인한다. 스킨마다 `B_s`는 달라도 된다. 해당 스킨 메시의 위치와 모프 델타에 `B_s`를 적용하면 공통 골격의 역 바인드를 통해 원본과 같은 선형 스킨 변형을 표현할 수 있다. 법선은 역전치로 변환하고 반사된 형상의 삼각형 와인딩을 바꾼다. 스킨 내부의 `B_s`가 다르거나 뼈 변환을 본체 TRS로 표현할 수 없으면 근사하거나 일부만 가져오지 않고 실패한다. 이는 임의의 바인드 포즈와 모든 외부 디포머를 지원한다는 뜻이 아니다.

스킨이 없는 메시와 스킨 메시가 섞이면 정적 노드의 현재 전역 변환을 해당 메시로 굽고, 가장 가까운 선택된 관절 노드가 있으면 그 본에 100% 가중한다. 해당 노드 자체가 관절인 경우도 포함한다. 관절 조상이 없으면 인공 루트에 100% 가중한다. 따라서 손 관절의 자식 소품은 손을 따라 움직이며, 독립 소품은 인공 루트를 따른다. 이 과정은 경고를 반환한다. 이후 GLB 출력은 합친 골격의 스킨 하나를 사용하므로 원본의 스킨 분리, 정적 노드 분류와 독립적인 노드 애니메이션을 그대로 복원하지 않는다. 스킨이 없는 메시만 있는 장면은 기존 정적 에셋 경로를 사용한다.

숫자 관절 ID를 담은 `extras.iiObject3D.semantics`가 있고 스킨마다 관절 대응이 다르면 어느 스킨에 대한 ID인지 모호하다. 기본값은 입력을 거부한다. `allowDiscardUnsupportedAttributes`를 명시하면 해당 의미 태그만 버리고 경고한다. 모든 스킨의 대응이 같으면 의미 태그를 그대로 가져온다. 이 정책은 해당 SDK 메타데이터에만 적용하며 일반 glTF 자료를 태그로 추측하지 않는다.

`maximumSkins`의 기본값은 4,096, 허용 범위는 1~100,000이다. `maximumSkinJointMappings` 기본값은 1,000,000, 허용 범위는 1~10,000,000이며 선택된 스킨의 `joints` 항목 합을 센다. 같은 스킨을 여러 메시가 사용해도 한 번만 센다. `maximumBones`는 중복을 합친 본과 필요한 인공 루트에 적용된다. 초과, 잘못된 관절·노드·역 바인드 또는 모호한 메타데이터를 만나면 새 에셋을 게시하지 않는다. 한도는 전체 프로세스 메모리 상한은 아니다.

선택된 스킨들이 같은 역 바인드 accessor를 공유하면 그 accessor는 한 번만 디코딩한다. 스킨에 실제로 필요한 가장 긴 앞부분만 캐시에 남기며, 보관하는 행렬의 총 개수는 스킨별 관절 대응 개수의 합을 넘지 않는다. 하나의 accessor 전체 디코딩에는 기존 문서의 accessor 예산과 `maximumBones`가 적용된다.

GLB 애니메이션과 원본 앱의 제약·제작 리그는 이 경로에서 가져오지 않는다. 실제 CC5·Blender·Unreal 앱은 사용자 지시에 따라 실행하지 않는다. [glTF 2.0의 스킨 규격](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html)을 기준으로 독립 파일 판독과 네이티브 수치 검사를 수행한다.
