# 명명 점 선택 집합 검증 — 2026-10-28

이 기록은 [점 선택 집합](NamedPointSelections.md)의 본체 API·프로젝트 이력 단계에 한정한다. 전체 캐릭터 생성·편집 목표의 완료를 뜻하지 않는다.

## 구현과 확인한 경계

- 일반 스냅샷과 템플릿 편집기에서 이름·가중치 저장, 교체, 이름 변경, 삭제, undo/redo를 확인했다. 같은 값의 반복 호출은 revision을 늘리지 않고, 선택만 변경할 때 본체 에셋을 새로 만들지 않는다.
- 서로 다른 두 메시의 편집이 있는 레이어에 하나의 선택을 적용하여 선택된 점에만 가중치를 주고, 선택에 없는 메시가 변경되지 않음을 확인했다. 조형 스트로크와 FBX 기반 외부 편집 병합 후에도 선택을 유지한다.
- 이름·UTF-8·메시 ID·중복 행·가중치 범위·1,024개 집합 한도를 검사했다. 본체 에셋을 제거한 뒤 조회나 변경이 허용되는 결함을 먼저 재현하고 수정했다. NSCharacter 참조는 엔진 소멸 후 만료된다.
- 점 수·폴리곤 연결 또는 렌더 메시 삼각형 연결이 바뀌는 교체는 거부하고, 원본 점 연결이 유지된 UV layout 변경과 메시 이름 변경은 허용한다. 호스트가 동일한 연결을 가진 메시의 점 ID를 임의로 바꾸는 행위는 추론할 수 없다.
- 버전 17의 저장·이력 복원, 기존 버전 8 프로젝트 읽기, 보존 이력에서 선택을 모두 제거한 뒤의 이전 버전 선택을 검사했다. 체크섬이 유효한 중복 이름과 원본 연결 불일치 이력은 기존 엔진 자료와 다음 ID를 보존하며 거부한다. 별도 Python 파서는 버전 17 헤더·CRC와 일반 손상 입력을 검사한다.

## 자동 검사

- macOS 일반 구성의 관련 회귀 119개와 NSCharacter가 없는 코어 전용 구성의 관련 회귀 115개가 통과했다. 이후 한도 상수 정리와 C++23 표준 모드 조정 후 선택·프로젝트 무결성 중심 15개를 두 구성에서 각각 다시 통과했다.
- 별도 설치 스테이징에서 일반과 코어 전용 소비자 각각 4개가 통과했다. 이 중 명명 선택 소비자는 실제 설치 헤더로 선택을 편집 레이어에 적용하고 프로젝트를 복원한다.
- 주소 및 정의되지 않은 동작 검사기(`-fsanitize=address,undefined`)로 빌드한 구성에서 선택·프로젝트 무결성 중심 15개가 통과했다.
- 실제 CC5·Blender·Unreal이나 SDK 사용자 앱은 사용자 지시에 따라 실행하지 않았다. Windows·Linux의 실제 빌드와 제작용 시각 품질은 이 기록에 없다.
