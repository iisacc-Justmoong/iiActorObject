# 2026년 10월 21일 변경 기록

iiActorObject 0.1.1의 Qt 기반 예제를 C++23 월드 개체 SDK로 교체하고, 0.2.1에서 USD 배치 레이어를 추가하였다. 이 문서는 소스 확보, Actor 구현, USD 호환성 및 빌드·검증 변경을 함께 기록한다. 구현과 검증은 사용자의 지시에 따라 AI 작업자인 Codex가 수행하였다.

## 변경 범위

| 단계 | 이전 상태 | 변경 결과 |
| --- | --- | --- |
| 0.1.1 → 0.2.0 | Qt Core·C++20의 `QString helloWorld()` 예제이다. | Qt 의존성을 제거하고 Actor·컴포넌트·공간 계층·수명주기를 C++23로 구현하였다. |
| 0.2.0 → 0.2.1 | 런타임 개체의 자체 공간 구조만 제공하였다. | Actor를 USD 스테이지에 배치할 수 있도록 USDA 스냅샷·외부 에셋 참조·prim 경로 매핑을 추가하였다. |
| 빌드와 패키징 | Qt 탐색과 예제 실행에 의존하였다. | 네이티브 공유·정적 라이브러리, 공개 헤더·CMake 타깃 설치 및 별도 소비자 검증으로 전환하였다. |
| 문서와 검사 | 예제 중심의 설명과 단일 실행 검사이다. | 객체 계약·USD 규약·마이그레이션·Windows 절차 및 실제 OpenUSD 통합 검사를 기록하였다. |

## Unreal Engine 소스 확보와 참조

설치된 `C:/Program Files/Epic Games/UE_5.8`에서 Unreal Engine **5.8.3, CL 58210709**의 소스를 확인하였다. 소스 자료는 Workspace 기준 `Reverse/Projects/Epic Games/Unreal Engine/`에 확보하였다. 해당 경로는 이 Git 저장소 바깥의 로컬 연구 자료이다.

확보 당시 원본·복사본 **141,594개 파일, 9,479,701,383바이트**를 SHA-256으로 대조하였으며 누락·추가·불일치는 0개였다. 근거는 해당 자료 폴더의 `_Acquisition/acquisition.json`, `_Acquisition/validation.json`, `build/manifest.sha256.jsonl`과 `README.acquisition.ko.md`이다. 설치본에 소스가 있었으므로 REA 도구 설치나 바이너리 역분석은 수행하지 않았다.

`GameFramework/Actor.h`, `Components/ActorComponent.h`, `Components/SceneComponent.h`에서 개체·동작·공간의 책임을 확인하고 iiSDK의 자체 인터페이스와 구현을 작성하였다. 외부 엔진 소스와 확보 자료는 이 패키지 또는 커밋에 포함하지 않는다. 이 작업으로 메타휴먼, 스태틱·스켈레탈 메시, 월드의 변환기나 전체 Unreal API가 구현된 것은 아니다.

## Actor 개체 모델

공개 헤더를 `include/iiActorObject/`로 분리하고 `iiActorObject.h`를 통합 진입점으로 유지하였다. Actor 구현은 기존 `iiActorObject.cpp`를 사용하며 나머지 구현은 `src/`에 둔다.

| 공개 객체 | 구현한 책임 |
| --- | --- |
| `Actor`, `ActorId` | 0이 아닌 프로세스 내 고유 ID, 이름·태그, 기본 루트와 컴포넌트 소유권이다. |
| `ActorComponent` | 동작 단위의 활성·Tick 상태 및 시작·프레임·종료 훅이다. |
| `SceneComponent` | 로컬 변환, 부모·자식 부착, 누적 월드 행렬이다. |
| `Vector3`, `Quaternion`, `Transform`, `Matrix4` | 위치·정규화 회전·스케일과 열 벡터 방식의 아핀 변환이다. |

Actor는 컴포넌트를 `unique_ptr`로 소유하며 복사·이동을 허용하지 않는다. Actor 메모리와 프레임 진행은 호스트 월드 엔진의 책임이다. iiActorObject는 상위 월드 엔진이나 다른 iiSDK 모듈을 참조하지 않는다.

수명주기는 `Created`, `Playing`, `Stopped`, `Destroyed`이다. `beginPlay()`는 Actor에서 컴포넌트 추가 순서로, `endPlay()`는 컴포넌트 역순에서 Actor 순서로 실행한다. `Stopped`에서 재시작할 수 있다. Actor Tick과 각 컴포넌트 Tick은 독립적으로 제어한다.

콜백 중 `destroy()`는 현재 디스패치가 반환될 때 처리한다. 논리 파괴는 메모리를 해제하지 않으며 C++ 소멸자는 사용자 수명주기 훅을 실행하지 않는다. 호스트는 삭제 전에 명시적으로 `destroy()`를 호출한다. 콜백 중 컴포넌트 추가·제거와 재진입 Tick은 거부한다.

공간 그래프는 같은 Actor 안에서만 구성한다. 순환·교차 Actor 연결과 루트의 부모 지정은 거부한다. 부착·분리는 로컬 변환을 유지하며, 자식이 있는 노드와 기본 루트는 제거할 수 없다. 행렬을 `parent * local`로 누적하여 비균일·음수·영 스케일도 표현한다. 비유한 입력·영 쿼터니언·음수 시간은 거부한다.

세부 계약과 실행 예는 [README](../README.md)의 객체 모델·소유권·공간 계층 설명을 따른다.

## USD 배치 호환성

`include/iiActorObject/Usd.h`와 `src/Usd.cpp`를 추가하였다. `exportUsdLayer()`는 `UsdActorPlacement`와 `UsdStageOptions`를 받아 UTF-8 USDA 텍스트와 Actor·컴포넌트·에셋의 prim 경로를 `UsdLayer`로 반환한다.

- Actor와 기본 루트는 단일 `Xform`으로 작성하여 변환 중복을 피한다. SceneComponent는 부모 계층의 중첩 `Xform`, 비공간 컴포넌트는 `Scope`이다.
- 분리된 SceneComponent에는 `!resetXformStack!`을 작성하여 자체 월드 변환 의미를 유지한다.
- `toUsdMatrix()`는 자체 열 벡터 행렬을 USD 행 벡터 규약에 맞게 전치한다. 변환 분해 없이 `matrix4d`를 기록한다.
- 이름·ID·태그·수명주기·Tick 상태를 `displayName` 및 `iiActor:*` 속성으로 보존한다.
- 외부 에셋은 별도 무타입 `Asset_<index>` 자식 prim의 reference로 작성한다. 에셋의 원래 스키마·변환을 보존하며 `instanceable`을 지정할 수 있다.
- `defaultPrim`, Y/Z up axis와 `metersPerUnit`을 선언한다. 좌표의 자동 회전·단위 변환은 수행하지 않는다.
- prim 이름·경로, UTF-8·문자열 이스케이프, 에셋 경로 구분자, 중복 배치·소유권·비유한 행렬을 검증한다.

파일 저장은 호스트가 맡으며 기존 iiFileProvider와 조합할 수 있다. 런타임에는 OpenUSD·Python·Qt·Unreal 의존성이 없다. 출력은 호출 시점의 배치 스냅샷이다. Actor 역직렬화, 실시간 양방향 동기화, 애니메이션, USD 스키마 플러그인, 메시·리그 데이터 변환은 구현 범위 밖이다. 사용 예와 전체 입력 계약은 [USD 문서](USD.md)를 따른다.

## 빌드·설치와 이전 방법

`CMakeLists.txt`와 `cmake/iiActorObjectConfig.cmake.in`에서 Qt 탐색·링크를 제거하고 C++23 요구사항과 공유·정적 export 정의를 소비자 타깃에 전달한다. `GenerateExportHeader`로 공개 export 헤더를 생성하며, 헤더·CMake 패키지·README·`docs/`를 설치한다. 공개 타깃 이름은 `iiActorObject::iiActorObject`이다.

`install.sh`는 빌드, 전체 CTest, 설치, 독립 소비자 빌드·실행을 순서대로 수행한다. Windows 드라이브 경로를 허용하고 CMake prefix의 세미콜론 구분을 보존한다. 테스트가 없으면 실패하도록 `--no-tests=error`를 사용한다. 작업 산출물과 검증용 의존성은 모두 `build/` 아래에 둔다.

0.1.x 소비자는 제거된 `QString helloWorld()` 호출을 새 Actor API로 교체하고 C++23으로 다시 빌드해야 한다. 0.2.1 소비자는 `find_package(iiActorObject 0.2.1 CONFIG REQUIRED)`로 설치본을 탐색한다. 상세 절차는 [Windows 빌드 및 실행](WindowsBuildAndRun.md)에 있다.

## 검증 결과

Actor·USD 공개 계약과 테스트를 구현 전에 작성하여 링크 실패를 확인한 뒤 구현을 완료하였다. 검증 호스트는 Windows x64, MSVC 19.51.36260, CMake 4.4.4, Ninja 1.13.2, Release이다. OpenUSD 검증용 버전은 `usd-core==26.8`이며 검증 패키지는 `build/usd-validation/`에만 설치하였다.

| 구성 | 소스 CTest | 설치본 소비자 | 결과 |
| --- | --- | --- | --- |
| 공유 라이브러리 | 15/15 | 1/1 | 통과이다. |
| 정적 라이브러리 | 15/15 | 1/1 | 통과이다. |

총 **32개 CTest 통과, 실패 0개, skip 0개**이다. 각 구성은 Actor 계약 8개, USD 계약 5개, fixture 생성 1개와 실제 OpenUSD 검사 1개를 실행하였다. 각 OpenUSD 검사는 Python unittest 6개로 구성된다.

실제 USD 파서에서 메타데이터, 네이티브 계산 15개 점의 월드 좌표, 분리된 노드, 비균일·음수·영 스케일, Xform/Cube·Sphere 참조, 인스턴싱, 상위 스테이지 reference 합성과 USDA→USDC 재개방을 확인하였다. 공유 DLL import는 MSVC·Windows 런타임뿐이며 설치본 소비자는 Python·OpenUSD 없이 Actor와 USD API를 링크·실행하였다.

전체 결과와 검사 대상 소스 19개 SHA-256은 [검증 요약 JSON](Verification-20261021.json)에 보존한다. 커밋 준비 시 현재 파일의 해시 및 JUnit 네 개를 원래 검증 기록과 다시 대조하였다. 상세 검사 목록과 로컬 로그 위치는 [검증 문서](Verification.md)에 있다. `build/`의 바이너리·로그·검증 패키지·생성 에셋은 커밋에서 제외한다.

MSVC 공유 클래스의 private STL 멤버에는 C4251 경고가 남아 있다. 동일 MSVC·STL·CRT 조합에서 설치본 소비자를 검증하였으며 컴파일러 간 바이너리 ABI는 보증하지 않는다. 다른 OS·모바일·WASM의 실행, 월드·렌더러·물리·네트워크 통합은 이번 검증에 포함하지 않는다.

## 원격 변경과 라이선스

커밋 준비 중 원격 `master`의 `6ceb713`(MIT 라이선스 전환)을 반영하였다. 자체 코드·문서의 MIT 조건을 유지하고 README의 라이선스 설명을 일치시켰다. Unreal 확보 자료와 검증용 제삼자 패키지는 이 저장소의 자체 코드에 포함하지 않는다.
