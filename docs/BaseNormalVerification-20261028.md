# 기준 법선 편집 검증 — 2026-10-28

이 기록은 [기준 법선 편집](BaseNormalEditing.md)의 코어·파일·소비자 검증이다. 전체 캐릭터 생성 목표나 대상 앱의 실행 호환성을 의미하지 않는다.

## 확인한 내용

- 동일한 원본 법선 ID를 공유하는 코너의 방향 편집과 위치·법선 동시 편집을 기준/편집 스냅샷에서 정본으로 병합했다. 렌더 전용 메시, 반대 방향의 법선, 기존 법선 보정 위의 추가 편집을 검사했다. 이미 분리된 기준 법선을 수정하지 않은 경우는 무변경으로 받아들이고, 공유 ID의 서로 다른 실제 편집과 잘못된 기준 법선은 원본을 바꾸지 않고 거부한다.
- 템플릿 파라미터 변경, 강도, 공유 법선에 대한 점 마스크 평균, 레이어 교체, undo·redo 및 프로젝트 복원을 검사했다. 위치만 바꾼 기존 편집이 새 법선 보정으로 잘못 분류되어 프로젝트 버전이 바뀌던 회귀를 수정하고 같은 검사를 다시 통과했다.
- 독립 Python 바이너리 FBX 리더가 편집 후 파일의 표준 `LayerElementNormal` 값과 네 코너 인덱스를 확인했다. 별도 프로젝트 헤더·CRC 검사에서 버전 19와 9개 손상 입력을 확인했으며, 그중에는 CRC가 유효한 범위 밖 법선 ID·중복 ID·비정규 회전도 포함한다. 복원 실패 시 기존 엔진 자원은 유지된다.
- 합성 DNA의 한 채널에 속한 두 모프 target과 기준 법선을 FBX를 거쳐 함께 편집한 후 DNA로 다시 저장했다. SDK와 별도로 OpenRigLogic 리더가 법선 방향, 두 target ID·델타와 리그 behavior를 검사했다. 일반·코어 전용 구성에서 각각 fixture를 포함한 3개 검사가 통과했다.
- 공개 CC0 MakeHuman 인체의 19,158개 제어점과 163개 본에 합성 모프와 법선 편집을 적용했다. NSCharacter의 본체 참조, 스냅샷과 비파괴 레이어, 파라미터 변경 후 복귀 및 버전 19 프로젝트 복원을 확인했다. 합성 편집의 수치 검사이며 상용 캐릭터 데이터나 시각 품질의 증거가 아니다.
- macOS arm64의 일반 구성에서 외부 편집·프로젝트·FBX·토폴로지·선택·레이어 관련 회귀 113개, NSCharacter 없는 코어 전용 구성에서 110개가 통과했다. 별도 설치 스테이징의 소비자 검사는 두 구성에서 각각 5개가 통과했다. 스테이징은 `build/`에 있으며 `~/.local`을 변경하지 않았다.
- 주소 및 미정의 동작 검사기(ASan·UBSan)를 활성화한 별도 C++23 빌드에서 법선 병합, FBX·프로젝트 검사와 레이어 검증을 포함한 6개가 통과했다.

실제 CC5·Blender·Unreal과 사용자용 앱은 실행하지 않았다. 새 법선 seam 작성, 제작용 외형·렌더링 품질과 다른 플랫폼의 빌드는 남은 작업이다.
