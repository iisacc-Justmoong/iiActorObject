# 템플릿 리그 전사 검증 기록

2026-10-28 macOS arm64에서 [템플릿 리그 전사](TemplateRigTransfer.md)를 C++23 네이티브 검사와 독립 형식 파서로 확인했다. 실제 CC5·Blender·Unreal 실행은 사용자 지시에 따라 수행하지 않았다.

- 같은 원본 점 ID의 합성 정적 메시에서 관절 앵커를 새로운 위치로 계산하고 모든 스킨 영향을 복사했다. 입력 위치·토폴로지·UV가 유지되고 새 에셋에서 가중치 편집과 undo·redo가 가능한지 검사했다. 토폴로지가 없는 렌더 정점 앵커에서도 전사, 템플릿 편집, 프로젝트 저장·복원 및 undo·redo를 확인했다.
- 이름에 따라 순서가 바뀐 두 메시를 대응하고 서로 다른 메시의 관절 앵커를 올바르게 다시 연결했다. 다른 토폴로지의 대상에는 명시적 앵커와 표면 스킨 보간을 적용했다. 누락·중복 메시 쌍, 다른 폴리곤 점 ID, 누락·중복 관절, 거리 제한, 유효하지 않은 방식, 이미 골격이 있는 대상, 충돌하는 의미 태그의 실패를 검사했다. 명시적으로 허용한 미대응 메시의 루트 가중치와 비충돌 루트 의미 태그를 보존했다.
- 템플릿과 대상이 서로 다른 엔진에 있을 때 결과가 대상 엔진에 소속되고, 템플릿 엔진이 소멸한 뒤에도 대상 엔진과 결과가 유효함을 확인했다. 오류가 나면 새 에셋이 등록되지 않고 입력이 변하지 않는다.
- CC0 MakeHuman 기준 메시의 19,158개 원본 점과 163개 관절을 정적 메시로 만든 뒤, 크기 1.08배와 위치 이동을 적용하여 리그를 전사했다. 모든 원본 점의 전체 스킨 영향과 본 ID를 비교했다. 관절 위치의 최대 오차는 약 `6.7e-16` 오브젝트 단위였다. 영향을 받는 관절 한 개를 0.2라디안 회전했을 때 최대 점 이동은 약 `0.0331`이었고, 기준 변형을 같은 크기·위치로 변환한 결과와의 최대 위치 오차는 약 `1.1e-15`였다. 한 시료·한 회전의 수치 결과이며 제작용 변형 품질 판단이 아니다.
- 독립 Python 파서가 전사 전후의 FBX에서 보이는 원본 점 13,380개, GLB에서 렌더 정점 14,517개의 모든 관절 영향과 가중치를 비교했다. 영향 수를 임의로 4개로 잘라 비교하지 않았다.
- 일반 구성의 신규 검사 6개와 관련 회귀 81개, `IIACTOROBJECT_WITH_NSCHARACTER=OFF` 구성의 관련 검사 83개가 통과했다. 구성과 묶음 사이에 같은 사례가 포함된다. 양쪽 모두 `IIACTOROBJECT_VALIDATE_APPLICATION_EXECUTION=OFF`다. 별도 스테이징 설치본을 이용한 코어·선택형 이미지 코덱·NSCharacter C++23 소비자 3개가 새 공개 API를 호출했으며 사용자 `~/.local` 설치본은 변경하지 않았다. 일반 공유 라이브러리에서 Qt 동적 의존성은 발견되지 않았다.
- AddressSanitizer·UndefinedBehaviorSanitizer 구성에서 네 가지 합성 경로와 인체 시료 1개가 통과했다. macOS 계측에서는 누수 검출을 활성화하지 않았다.

다른 토폴로지에서의 관절 앵커는 호출자가 지정하며, 표면 스킨 전사는 기준과 대상이 공간적으로 가까워야 한다. 임의 사람 메시의 완전 자동 랜드마크·리그 생성, DNA 프로그램의 변환, CC5·MetaHuman 제작용 형태와 실제 앱 호환성은 이 검사로 입증되지 않는다.
