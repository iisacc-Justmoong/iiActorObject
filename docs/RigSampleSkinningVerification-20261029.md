# 리그 샘플의 비선형 스킨 검증 기록 — 2026-10-29

## 문제와 수정

리그 제어를 모프로 샘플링할 때 렌더 정점은 원본 DQ·혼합 스킨을 사용했지만 작성용 원본 점과 렌더되지 않는 법선에는 항상 선형 스킨을 적용했다. 기준 형상은 이미 원본 스킨 방식으로 구워졌기 때문에 두 본 이상의 영향을 받는 점의 새 모프 끝점이 실제 리그 평가와 달라질 수 있었다. 새 회귀 사례는 수정 전 실제로 실패했다.

본체 엔진은 이제 각 원본 점의 스킨 프로필을 사용하여 포인트와 사용하지 않는 법선을 샘플링한다. 원본 점 ID, UV·법선 분리와 기존 모프는 유지한다. 출력은 기존대로 원본 스킨을 보존하거나, 별도 오버로드에서 `LinearizeAtBind`를 선택할 수 있다. NSCharacter는 본체 에셋을 참조하며 해당 호출을 전달한다. 기존 호출과 옵션 구조는 유지한다.

## 자동 검사

- 코어 전용, NSCharacter 포함, ASan·UBSan 구성에서 각각 관련 테스트 38개가 통과했다. 누수 검사는 끈 ASan 설정이며 UBSan 오류는 즉시 실패하도록 했다.
- DQ 전체 적용과 점별 혼합을 각각 시험했다. Raw·GUI 입력, 두 모프 끝점, 혼합값의 0·중간·1, 겹치는 원본 모프, UV 이음새, 표시된 비가중 포인트, 숨겨진 가중·비가중 포인트와 렌더되지 않는 법선을 다룬다. 숨겨진 포인트와 법선은 같은 입력의 별도 렌더 메시를 기준으로 비교했다. 기본 보존 호출과 명시적 보존 호출도 비교했다.
- 스킨 보존과 선형화 양쪽에서 기준 및 요청 끝점을 런타임과 비교하고 네이티브 프로젝트 저장·복원 뒤에도 확인했다. 비선형 프로필의 직접 GLB 출력은 거부되고 선형화된 출력은 생성된다. 잘못된 정책과 작업량 초과는 새 에셋을 등록하지 않는다.
- 코어 전용 및 NSCharacter 포함 패키지를 `build/` 아래에 각각 설치하여 별도 소비자에서 새 오버로드, 원본 프로필 보존, 선형화된 GLB와 런타임 끝점을 확인했다. 실설치 위치는 변경하지 않았다.
- `resources/MakeHuman` 기반 인체의 기존 DQ 런타임 테스트도 통과했다. 이는 이번 리그 샘플 변경을 제작용 인체 자료로 전체 검증했다는 뜻은 아니다.
- DNA를 포함한 별도 빌드에서 독립 테스트 DNA 생성, 리그 스냅샷·샘플 평가와 비선형 회귀 등 4개 검사가 통과했다. 이는 합성 자료에 한정된다.
- 관련 변형 스냅샷의 선형화 GLB는 세 구성에서 독립 디코더가 바인드 행렬·가중치·위치와 모프 법선을 검사했다. 새 리그 샘플에서 생성된 GLB는 생성 가능 여부만 확인했다.

## 한계

선형화는 선택한 기준과 개별 모프 끝점의 바인드 자세 결과를 보존한다. 다른 관절 자세, 여러 모프의 동시 혼합, DQ의 모든 연속 애니메이션을 동일하게 재현하지 않는다. 선형화 호출은 현재 C++ API에 있고 명령행 도구에는 없다. GLB 생성 확인만으로 다른 앱의 가져오기 결과를 보장하지 않는다. CC5·Blender·Unreal 등 앱은 사용자 지시에 따라 실행하지 않았다. 제작용 MetaHuman DNA와 CC5 전용 워크플로의 전체 호환성은 미검증이며 원래 목표의 나머지 작업은 계속 남아 있다.
