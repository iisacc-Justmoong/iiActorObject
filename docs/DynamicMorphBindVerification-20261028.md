# 템플릿 형상과 인스턴스 바인드 검증 — 2026-10-28

## 검사 대상

공용 `Pose`의 인스턴스별 변형 바인드, 템플릿 모프 리그의 기준 입력·끝점 합성, 소스 관절 재평가와 메시 채널 동기화를 검사한다. 본체 `Object3DEngine`이 템플릿·에셋·리그와 캐시를 소유하고, 각 액터가 포즈와 모프 값을 보관한다. NSCharacter는 같은 본체 자료를 참조한다.

합성 골격에서 형상에 맞춘 바인드와 원래 기준 로컬 애니메이션으로 평가한 월드·스킨 행렬을, 별도로 생성한 새 기준 골격의 결과와 비교한다. 중립·중간·끝점 모프, 로컬 포즈 유지, 같은 입력 재적용의 캐시와 revision, `copyFrom`, `reset`, 바인드 제거, 역바인드 및 스킨 법선을 검사한다. 유효하지 않은 기준 입력, 소스 제거, 다른 액터, 이름이 변경된 재연결 골격은 오류로 거부하며 액터 상태를 유지한다. 아주 작은 바인드 스케일에서 두 배의 보정을 단위 보정으로 오인하지 않는지도 검사한다.

변형 바인드의 2본 IK, 방향 맞춤, 관절 프레임 맞춤을 검사한다. 회전으로 표현할 수 없는 보정은 오류로 거부한다. 이 단계 당시에는 인스턴스 바인드가 활성화된 포즈 리타깃을 거부했으며, 이후 [포즈 리타깃](PoseRetarget.md)에서 지원 범위를 확장했다. 복원한 버전 21 프로젝트의 리그 두 개를 각기 다른 입력으로 적용하여 각 액터의 바인드가 독립적인지 확인한다.

## 구성별 결과

표준 구성의 캐릭터·포즈·템플릿·프로젝트 관련 검사 82개와 NSCharacter 제외 코어 구성의 같은 범주 79개가 통과했다. 빌드 안에 별도로 설치한 NSCharacter 포함 소비자, 코어 전용 소비자와 VisualCodec 소비자도 각각 새 공개 헤더와 라이브러리를 사용해 통과했다. 전역 설치본은 교체하지 않았다.

AddressSanitizer와 UndefinedBehaviorSanitizer를 켠 바인드·포즈·모프·프로젝트 관련 검사 13개가 통과했다. 이 환경에서 누수 검출은 비활성화했으므로 누수 검사 결과는 아니다.

CC0 인체 자료의 몸·눈·치아·혀 네 메시, 렌더 정점 20,569개를 사용해 별도로 생성한 목표 형상과 비교하였다. 형상 변화로 위치가 가장 많이 달라진 스킨 관절 중 하나인 원본 ID 123은 0.00372m 이동했고, 해당 관절과 루트를 회전시킨 결과의 최대 정점 위치 오차는 약 `7.55e-16`m였다. 이 수치는 해당 템플릿과 입력 표본의 네이티브 계산 결과이며 제작용 캐릭터의 시각 품질 검증은 아니다.

## 범위와 한계

새 바인드의 관절은 원본 템플릿의 합성 입력으로 평가한다. 베이크된 메시 모프는 선형으로 합성되므로 비선형 형상이나 복합 슬라이더에 대한 전체 표면 일치는 보장하지 않는다. 값이 바뀔 때 큰 템플릿의 계산 시간은 별도로 측정해야 한다. FBX·GLB 동적 바인드 제어기 출력은 포함하지 않는다. CC5·Blender·Unreal은 실행하거나 가져오지 않았다.
