# 듀얼 쿼터니언 런타임 검증

2026-10-28 macOS arm64에서 [공용 듀얼 쿼터니언 스키닝](DualQuaternionSkinning.md)을 네이티브 C++로 검사했다. CC5·Blender·Unreal 및 기타 사용자용 앱은 실행하지 않았다.

- 반대 방향 90도 회전의 두 본에서는 선형 스키닝이 수축하는 점을 DQ가 보존하는지, 0·0.5·1 혼합이 각각 기대 위치를 주는지 확인했다. 반대 방향 170도 회전과 영향 배열 순서 변경에서도 회전 부호를 정렬한다.
- DQ 100%에서 선형 법선이 상쇄되는 경우, 한 본의 비균일 배율·반사와 모프 위치·법선, 0 비율에서의 기존 선형 결과를 비교했다. 전단·잘못된 가중치와 버퍼·다른 골격은 거부하고 출력은 유지된다.
- 런타임 컴포넌트의 변경 없는 재평가, LOD별 값 복원, 빈 값의 선형 복귀를 검사한다. 작성용 원본 점의 선택값을 UV 이음새를 포함한 렌더 정점으로 확장하며 잘못된 값과 차원을 거부한다.
- 별도의 ufbx 참조 계산과 서로 다른 두 본의 회전·이동·축별 배율 34개 시료에서 위치를 혼합값 0·0.3·1로 비교했다. DQ 100%의 법선과 서로 반대에 가까운 170도 회전도 비교했다. 혼합 법선은 양 구현의 계약이 다르므로 참조 일치를 주장하지 않는다.

CC0 인체의 163개 본과 14,517개 렌더 정점에서 다중 본 가중치가 있는 부위의 본 하나를 0.2라디안 회전했다. 해당 본에 영향받는 다중 가중치 정점은 3,311개였고 DQ 결과의 최대 이동은 `0.0330555`, 선형 결과와의 최대 위치 차이는 `0.000567502` 오브젝트 단위였다. 모든 결과는 유한하고 법선 길이는 1이었다. 한 본·한 자세의 수치 시료이며 DQ 결과가 해부학적으로 더 우수하다는 시각 품질 판정은 아니다.

일반·코어 구성의 CMake 검사 7/7이 각각 통과했으며, 본체 에셋으로 만든 두 인스턴스의 독립적인 선형·DQ 설정과 일반 구성의 NSCharacter 참조 검사가 포함된다. ufbx 참조 검사도 두 구성에서 각각 1/1 통과했다. 기존 캐릭터 회귀 검사는 일반·코어 각각 6/6 통과했다. 별도로 설치된 일반·코어 소비자 검사도 각각 1/1 통과했다. 인체 시료는 네이티브 테스트 실행 파일을 직접 호출했으며 CMake 테스트 정의에도 추가했다. FBX·GLB의 DQ 입력·출력이나 제작용 캐릭터의 전체 변형 품질에 대한 근거는 아니다.

두 공유 라이브러리의 동적 의존성에는 Qt가 없고 C++ 표준 라이브러리와 macOS 시스템 라이브러리가 확인됐다. 설치 소비자는 `build/` 아래의 스테이징을 사용했으며 `~/.local` 설치본은 갱신하지 않았다.
