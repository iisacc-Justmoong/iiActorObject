# 인체 기준 자세 계획

`planHumanReferencePose`는 인체 역할 매핑과 오브젝트 좌표축을 받아 방향·손목 프레임·실행 순서로 이루어진 편집 가능한 계획을 만든다. 계획은 문자열과 숫자 메타데이터이다. 골격·메시·평가 Pose·편집 이력과 새 에셋은 iiActorObject 본체가 소유한다. 다른 계획기가 같은 형식의 방향·프레임·순서를 만들어 기존 어댑터에 전달할 수 있다.

## 생성 규칙

기본 좌표는 왼쪽 +X, 위 +Y, 앞 +Z이다. `left`, `up`, `forward`를 호출자가 지정할 수 있으며 각 축은 유한하고 서로 직교해야 한다. 길이는 정규화한다. 두 좌표계의 손잡이 방향을 모두 허용한다. 기본 계획은 양쪽 위팔과 아래팔을 좌우로, 허벅지와 종아리를 아래로, 발끝 방향을 앞으로 맞춘다. 손목 프레임은 중지 첫 관절을 주 방향으로, 엄지 첫 관절과 만드는 기하 면으로 정한다. 왼쪽 면 법선은 `cross(left, forward)`, 오른쪽은 그 반대이다. 각 분기를 독립적으로 끌 수 있다.

손가락은 팔과 손목을 보정한 뒤 각 첫째·둘째 관절의 방향을 본체에서 측정한다. 둘째에서 셋째로 향하는 구간을 그 방향에 맞춰 펴므로 손가락마다 기존 벌어짐을 유지한다. 넷째 역할이 존재하면 셋째에서 넷째도 같은 방향으로 맞춘다. 셋째 뒤의 관절이 없으면 끝 마디의 방향은 추정하지 않는다. 손가락 계획은 해당 손가락의 1·2·3 역할이 모두 있어야 한다.

기본값은 필요한 역할이 없으면 해당 제약을 건너뛰고 `skipped`에 이름과 누락 역할을 남긴다. 호출자는 계획을 적용하기 전에 이 목록을 확인한다. `skipMissingRoles=false`로 지정하면 누락 시 오류이다. 공통 `ToeBase`가 있으면 이를 우선한다. 없고 MakeHuman의 `toe1-1`부터 `toe5-1`까지 다섯 원본 본이 모두 있으면 해당 발 관절에서 다섯 발가락 시작점의 중심으로 향하는 방향을 앞으로 맞춘다. 일부만 있으면 임의의 발가락으로 대체하지 않고 기존 누락 규칙을 따른다. 같은 이름의 의미 태그와 실제 본이 다르면 모호한 대응을 거부한다. 본 ID는 계획을 만든 현재 본체 에셋의 참조이며 본체가 유효한 후손과 중복을 검사한다. 없는 넷째 손가락 역할은 선택사항이므로 건너뛴 오류로 보고하지 않는다. 퇴화한 손 프레임, 조상이 아닌 후손, 영벡터, 제한 초과는 오류이며 원본·편집 이력·엔진 자원을 바꾸지 않는다. 계획의 방향·프레임·순서는 호출자가 교체할 수 있다.

```cpp
#include <iiActorObject/NSCharacter/HumanPosePlanner.h>

using namespace iiActorObject::NSCharacter;
HumanPosePlanOptions options;
options.left = {1, 0, 0};
options.up = {0, 1, 0};
options.forward = {0, 0, 1};
auto plan = planHumanReferencePose(mapping, options);
setHumanOrderedReferencePose(editor, mapping, plan.directions, plan.frames,
                             plan.order, plan.referenceOptions);
```

매핑은 적용하려는 현재 에셋을 가리켜야 한다. 계획을 만든 후 에셋을 편집하거나 기준 골격을 바꾸면 현재 에셋을 다시 매핑하고 계획을 다시 만든다. [본체 기준 자세](PoseReference.md)는 순서와 이력을 저장하며, 별도의 교환 스냅샷을 생성할 수 있다.

## 범위

이 계획은 좌표축에 따른 일반 기준 자세이다. CC5·Unreal·MetaHuman의 모든 본 기준 회전, 비틀림, 컨트롤 리그·표정 리그·애니메이션 재타깃을 재현하는 캘리브레이션이 아니다. 관절 길이·위치를 바꾸거나 표면 충돌·손가락 접촉을 해결하지 않는다. CC5·Blender·Unreal 및 사용자용 CLI 실행 검증은 현재 사용자 지시에 따라 수행하지 않는다.

`tests/HumanPosePlannerTest.cpp`는 프로시저 인체, 좌표축 변경, 부분 역할, 다섯 발가락 중심과 누락·모호성, 예산·수명과 별도 CC0 성인·아동 자료의 네이티브 경로를 검사한다. 이 검사는 대상 앱의 가져오기나 최종 외형 품질을 증명하지 않는다.
