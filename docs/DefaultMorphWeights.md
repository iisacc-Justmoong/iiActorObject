# 메시의 기본 모프 값

`Object3DMesh::morphDefaults`는 모프 이름과 새 인스턴스에 적용할 초기 값을 보관한다. 지정하지 않은 모프는 0이다. 값은 본체가 소유한 중립 메시와 델타를 변경하지 않는다. `Object3DAsset::instantiate()`가 각 메시 컴포넌트에 해당 값을 설정하며, 이후 인스턴스별 가중치 변경은 원본 자산이나 다른 인스턴스에 영향을 주지 않는다. `NSCharacter::CharacterAsset`은 기존과 같이 본체 에셋을 참조한다.

모든 이름은 해당 메시의 논리 모프 이름이어야 하며 중복 이름과 유한하지 않은 값은 거부한다. 0은 저장 목록에서 제거한다. 음수와 1을 넘는 유한 값은 자르지 않는다. 이름으로 저장하므로 다른 모프를 추가해도 기존 기본값이 다른 타깃을 가리키지 않는다. 원본 모프를 이름 변경할 때 기존 논리 채널이 남으면 양쪽에 같은 값을 유지하고, 서로 다른 기본값을 가진 채널을 하나로 합치는 변경은 거부한다.

`Object3DEditor::setDefaultMorphWeight(mesh, name, value)`와 NSCharacter 편집기 동명 함수는 새 스냅샷으로 변경하며 실행 취소·재실행을 지원한다. 기본값 변경은 현재 템플릿 편집 레이어의 보정 항목이 아니므로 레이어 상태에서는 명시적으로 거부한다. 필요하면 템플릿을 분리한 뒤 변경한다. `bakeMorphs`는 호출자가 지정한 양을 기준 메시로 굽는 별도 연산이며 기본값을 자동으로 제거하지 않는다.

명시적인 가중치를 기준으로 만드는 변형 스냅샷은 그 형상을 새 0 상태로 삼으므로 결과의 기본 모프 값을 제거한다. 자세만 굽는 스냅샷은 기본 모프 값을 유지한다. DNA 소스에는 임의의 메시 기본값을 연결할 계약이 없으므로 기본값이 남은 자산의 DNA 소스 출력은 거부한다. 호출자가 값을 명시적으로 정리한 뒤 출력할 수 있다.

GLB 가져오기는 노드의 `weights`가 있으면 이를 사용하고, 그렇지 않으면 메시의 `weights`를 사용한다. 둘 다 없으면 0이다. 같은 GLB 메시를 여러 노드가 참조할 때 각 본체 메시에는 해당 노드의 값이 저장된다. GLB 출력은 메시 기본값을 기록하며, 모프 애니메이션에서 연결되지 않은 타깃에도 이 값을 사용한다. GLB 값은 float32 표현 범위로 내보내므로 반올림이 발생할 수 있고, 범위를 넘거나 0이 아닌 값이 0으로 소실되면 거부한다.

FBX 출력은 논리 모프의 기본값을 `DeformPercent`로 기록하고 입력은 해당 채널의 값을 읽는다. 같은 논리 모프에 연결된 여러 원본 레코드의 초기 값이 서로 다르면 하나의 기본값으로 합칠 수 없어 입력을 거부한다. progressive blend shape나 앱별 제어 그래프의 의미를 이 값만으로 복원하지는 않는다.

별도의 [점진 모프 FBX 교환](ProgressiveMorphRig.md)은 원본 기본 제어값을 중간 타깃의 유효 가중치로 변환해 에셋에 설정하고, 원본 제어값과 키를 본체 리그에 보관한다. 전용 정적 출력은 이 두 기본값이 허용 오차 안에서 일치할 때만 내보낸다. 일반 FBX·GLB 출력을 이 리그의 보존 형식으로 취급하지 않는다.

현재 자산이나 저장 이력에 기본값이 있으면 프로젝트 버전 23을 사용한다. 이전 버전은 기본값이 모두 0으로 복원된다. 공개 C++ 자료 구조와 프로젝트 형식이 확장되므로 바이너리 소비자는 새 헤더와 라이브러리로 다시 빌드해야 한다. 실제 CC5·Blender·Unreal 앱의 실행 검증은 사용자 지시에 따라 수행하지 않는다.
