# 여러 메시의 점진 표정 FBX 교환 검증

## 변경한 동작

서로 다른 메시들이 하나의 점진 모프 제어를 공유하면 본체는 메시별 FBX 지오메트리와 채널을 내보낸다. 애니메이션이 있으면 해당 제어 곡선을 각 채널에 기록한다. SDK 작성용 메타데이터가 남아 있으면 전용 FBX 입력이 여러 채널을 하나의 본체 리그 제어로 복원한다. 동일하고 독립 모프 손실이 없는 메시 인스턴스는 기존처럼 하나의 FBX 지오메트리를 공유한다.

공동 제어 메타데이터의 식별자·채널 수·이름·기본값·중간 형상 이름과 가중치를 검사한다. 애니메이션 입력은 채널마다 평가한 값을 원본 키와 표본 위치에서 비교한다. 값이 다르거나 메타데이터가 불완전하면 에셋과 리그를 엔진에 등록하지 않고 실패한다. 이산 검사 지점 사이의 완전한 곡선 일치가 보장되는 것은 아니다.

## 검사한 내용

- 서로 다른 세 메시에서 `Expression`은 첫째·둘째를, `Blink`는 첫째·셋째를 구동하도록 했다. 각 메시의 형상과 일부 스킨이 다르며 셋째 메시에는 독립적인 일반 모프가 있다. 0이 아닌 기본 제어값, 두 중간 형상 구간, 각 메시의 변형과 일반 모프를 확인했다.
- 독립 FBX 바이너리 판독으로 세 메시와 각 지오메트리에 연결된 채널, 두 공동 제어의 메타데이터와 서로 다른 형상 데이터, 채널에 각각 기록된 애니메이션 키를 확인했다. MIT ufbx로 같은 표정값을 각 채널에 적용하여 메시별 변위와 FBX 애니메이션 평가값을 확인했다.
- 시작 시각이 다른 두 테이크를 내보내고 다시 가져와 각 부위의 결과를 확인했다. 공동 제어 채널의 곡선이 점진 형상 간격을 반영한 오차를 넘으면 일반 모프 오차 한도보다 작은 차이여도 거부했다. 불완전하거나 서로 충돌하는 그룹 정보, 서로 다른 중간 형상 가중치도 거부했으며 실패 시 엔진 객체 수가 바뀌지 않았다.
- 작성용 메타데이터 복원을 끄면 각 FBX 채널이 별도 제어로 읽히고 경고가 남는다. 동일 인스턴스의 공유 지오메트리 경로와 다른 스킨·형상·독립 모프가 있는 경우의 분리 경로를 함께 검사했다.
- CC0 MakeHuman 인체와 머리카락에 시험용 공동 변형 두 단계를 작성해 애니메이션 FBX를 출력·입력하고, 두 부위의 이동량과 재입력 결과를 비교했다. 시험용 변형은 제작용 표정이나 머리카락 품질의 판정이 아니다.

## 빌드와 검사 결과

- macOS arm64 C++23 Release: 점진 모프·애니메이션과 독립 판독 23/23이 NSCharacter 포함 구성과 본체 전용 구성에서 각각 통과했다. 결과는 `build/glb-import-ninja/progressive-split-final.xml`과 `build/core-tangent-ninja/progressive-split-final.xml`이다.
- FBX 애니메이션·토폴로지 관련 회귀 28/28이 통과했다. 인체·머리카락 연결 검사는 별도 1/1이다. 결과는 `build/glb-import-ninja/progressive-split-fbx-regression.xml`과 `progressive-split-human.xml`이다.
- Debug ASan·UBSan: 점진 모프·애니메이션 검사 23/23이 통과했다. 누수 검출은 비활성화했다. 결과는 `build/glb-import-full-asan/progressive-split-final.xml`이다.
- `build/`에 별도로 설치한 NSCharacter 포함 소비자와 본체 전용 소비자가 서로 다른 두 메시의 공동 제어와 애니메이션 FBX 왕복을 각각 통과했다. 사용자 설치본은 변경하지 않았다.
- Emscripten C++23으로 변경한 FBX 구현의 구문을 확인했다. macOS 빌드의 생성된 설정을 사용했으며 WebAssembly 링크나 실행을 확인한 것은 아니다. macOS 본체 라이브러리의 직접 동적 의존성에 Qt는 없다.

## 남은 범위

외부 앱은 메시별 채널을 따로 표시할 수 있으며, 작성용 메타데이터를 제거할 수도 있다. 이 경우 SDK가 원래의 공동 제어 관계를 추측하지 않는다. 외부 앱의 전용 제어 그래프, 원본 모프 레코드 ID, 제작용 얼굴 형상과 시각 품질은 이 교환만으로 복원되지 않는다. 여러 원본 모프 레코드로 이루어진 타깃과 layout별로 서로 다른 점진 모프 법선의 출력 제한도 남아 있다.

사용자 지시에 따라 CC5·Blender·Unreal이나 사용자용 앱은 실행하지 않았다. 따라서 실제 앱에서의 가져오기, 제어 UI, 시각 품질과 전체 MetaHuman 수준 목표는 이 검사로 확인되지 않았다. 기능 계약은 [점진 모프](ProgressiveMorphRig.md)와 [점진 애니메이션](ProgressiveMorphAnimation.md)에 있다.
