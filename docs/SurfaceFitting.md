# 명시적인 의상·표면 충돌 맞춤

이 문서는 명시적인 스냅샷 맞춤 연산을 다룬다. 생성 파라미터와 편집 계층의 변경에 따라 지속적으로 재계산하는 설정은 [자동 표면 맞춤](AutomaticSurfaceFitting.md)을 따른다.

## 계약

`fitMeshSurface`는 `SurfaceCollider` 인터페이스에 의존하는 본체 연산이다. 현재 메시를 장애물 밖으로 이동하여 양의 여유 거리를 확보한다. 원본 제어점 ID·연결·UV·스킨·모프 식별을 유지하고 기준 법선과 파생 렌더 캐시를 갱신한다. NSCharacter는 본체 편집 세션에 호출을 전달한다.

`clearance`는 양수이며 `tolerance`보다 커야 한다. 점과 면의 충돌, 최대 이동 거리, 반복 횟수와 질의 예산을 검사한다. 기본은 면 내부의 충돌까지 확인한다. 점만 검사하는 선택은 면 전체의 충돌 제거를 보장하지 않는다.

`mobility`는 정규화한 역질량의 상대 비율이다. 0은 고정점이며 부분 값은 여러 점에 분배하는 제약의 상대 이동량을 정한다. 조형 브러시의 단순 강도 마스크와 다르다. `relaxation`은 접촉 투영의 강도, `edgeStiffness`는 작업 시작 형상의 모서리 길이를 유지하는 정도이다.

제약의 위치 투영은 [Müller 등의 Position Based Dynamics](https://matthias-research.github.io/pages/publications/posBasedDyn.pdf)의 제약식에 따른다. 이 연산에는 시간 적분·중력·속도·마찰이 없으며 동적인 천 시뮬레이터는 별도 기능이다.

`escapeConcavities`는 기본적으로 활성화한다. 국소 투영이 6회 연속 충분히 개선되지 않으면 고정점을 유지한 채 26개 방향과 최대 24개의 증가 반경에서 유효한 점·면 위치를 찾는다. 삼각형 이동에는 상대 이동 비율을 적용한다. 후보는 모든 장애물의 점·면 조건, 원본 위치 기준 이동 한도, 질의 예산을 만족할 때만 채택한다. `escapeTrials`·`escapePointProjections`·`escapeTriangleProjections`로 비용과 적용 수를 구분한다. 기존 국소 투영만 사용하려면 해당 옵션을 끈다.

이 탐색은 오목한 틈에서 반대 기울기를 번갈아 따르는 경우를 보완하는 유한 탐색이다. 전역 최적해·임의 입력의 수렴이나 재단된 옷의 형상 품질을 보장하지 않는다. 점·면의 자체 교차 검사와 천의 굽힘 모델은 별도 기능이며, 큰 보정 뒤에는 최대 이동량과 모서리 변형률도 확인한다.

## 실패와 이력

고정점·이동 제한·예산·반복 제한 때문에 제약을 만족하지 못하면 기본적으로 실패하며 메시와 편집 이력은 유지한다. `allowUnresolved`는 미해결 상태를 포함하는 명시적인 미리보기 출력이다. 반환값의 잔여 점/면 제약과 `converged`를 확인한다.

본체와 캐릭터 편집기의 `fitSurface`는 결과를 기존 편집 계층과 undo/redo로 저장한다. 자체 프로젝트 버전 8은 수정된 점을 기존 필드로 보관한다. 충돌체·맞춤 레시피·자동 재실행 정책을 프로젝트에 암묵적으로 추가하지 않는다. 생성 파라미터·몸 조형·스킨 포즈를 바꾼 후에는 새 형상에서 다시 맞춘다.

외부 FBX·GLB는 맞춘 메시·스킨·모프를 받는다. 최종 의상 품질, 자기 충돌·재단·자세 보정과 실제 앱 편집은 전체 목표에서 계속 구현·검증해야 한다.

## 사용

본체 편집 세션에서 현재 몸의 파생 충돌 스냅샷을 만들고 같은 에셋의 의상에 적용하는 예이다. `bodyIndex`와 `garmentIndex`는 서로 다른 메시 인덱스이다.

```cpp
auto body = iiActorObject::MeshCollider::fromMesh(
    editor.get().object().get().data().meshes[bodyIndex]);
iiActorObject::SurfaceFitOptions options;
options.clearance = .002;
options.tolerance = 1e-5;
const auto result = editor.get().fitSurface(garmentIndex, body, options);
```

여러 고체와 동시에 맞추려면 `SurfaceCollider` 포인터의 span을 전달한다. 호출 중 충돌체가 유효해야 하며 편집 세션은 해당 포인터를 보관하지 않는다. 원본 제어점 수에 맞춘 `mobility`를 전달하면 고정점과 상대 이동 비율을 지정할 수 있다. `maximumDisplacement` 기본값은 0.25이며, 점·삼각형·반복·공간 질의의 한도는 호출자가 설정한다.

## 인체와 실제 앱 검사

`tests/SurfaceFittingHumanTest.cpp`는 19,158개 원본 점의 몸에서 검증용 의상 표면을 생성하고 2,648개 표시 제어점에 스킨·표면 연결을 전사한다. 성인은 6회, 아동은 2회 반복으로 수렴하였다. 현재 형상으로 다시 검사했을 때 이동이 없어야 하며, 프로젝트 저장·복원·undo/redo·형상 재생성과 얼굴 리그 재연결도 확인한다.

작성용 몸의 쿼드는 원본 그대로 유지한다. FBX를 읽는 앱마다 비평면 쿼드의 대각선 선택이 달라질 수 있으므로 이 검증에서는 각 쿼드의 두 대각선에 해당하는 몸 충돌체를 함께 사용한다. 새 의상은 삼각형으로 작성하여 출력 중 면의 의미가 바뀌지 않게 한다. 생성된 의상 조각은 충돌 검증용이며 재단된 제작용 옷이 아니다.

`tests/VerifySurfaceFittingBlender.py`는 실제 Blender에서 성인·아동의 GLB·FBX 네 입력을 연다. 가져온 5개 메시·163개 본·의상 60개 모프와 나머지 메시별 59개 모프, 기준 위치와 스킨 움직임을 검사한다. 표시 의상 정점의 안팎은 배정밀도 삼각형 교차로 검사하고, 의상 전체 삼각형의 여유 거리는 공간 격자로 후보를 보수적으로 줄인 후 정점/면·모서리/모서리·모서리/면 계산으로 확인한다. 정점만 샘플링하여 면 전체 검사를 대체하지 않는다.

요청 거리는 2mm, 본체 허용 오차는 10μm이다. 실제 입력 네 건의 최소 삼각형 여유 거리는 약 1.9900mm 이상이며 형식과 Blender의 단정밀도 표현에 추가 2μm를 허용한다. 본 회전 후 스킨 이동은 별도 검사이며, 움직인 자세에서의 의상 충돌 제거를 입증하지 않는다. FBX의 서로 다른 레이아웃 모프 법선은 명시적으로 허용한 SDK 메타데이터에 보존한다. 실제 Blender에서 해당 법선 메타데이터가 적용된다는 의미는 아니다.

동결 소스·설치 패키지·빌드 구성·수치와 산출물은 [SurfaceFittingVerification-20261027.json](SurfaceFittingVerification-20261027.json)에 기록한다.

선택적인 [형상 정리](SurfaceFairing.md)는 `options.fairing.iterations`가 양수일 때 이번 충돌 보정 변위의 연속성을 개선한다. 원래 작성 형상을 평활화하지 않으며, 같은 이동·고정점·질의 한도 아래에서 목적함수를 낮춘 유효 결과만 채택한다. 기본값 0은 기존 계산을 유지한다.
