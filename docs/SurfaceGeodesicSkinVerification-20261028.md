# 표면 최단 경로 스킨 바인딩 검증 기록

2026-10-28 macOS arm64에서 [표면 최단 경로 바인딩](SurfaceGeodesicSkin.md)의 본체·캐릭터 편집 연결을 검사했다. 실제 애플리케이션이나 제작용 자동 리깅 품질의 검증은 아니다.

- 가까이 붙어 있으나 메시 연결은 아래쪽으로 우회하는 두 표면에서, 새 방식이 기존 직선거리 엔벌로프보다 반대쪽 본의 가중치를 각각 10분의 1 미만으로 만든 합성 사례를 검사했다. 뼈별 수동 시드를 서로 바꾸면 결과도 바뀐다. 별도의 삼각형에서는 두 뼈에 대한 최단 거리와 정규화 가중치를 손계산으로 확인하고 동점의 작은 본 ID 우선과 입력 순서 독립성을 검사했다.
- UV 경계로 렌더 정점이 갈라져도 같은 원본 점의 스킨이 일치하는지, 토폴로지가 없는 분리 정점을 자동 용접하지 않는지 확인했다. 도달할 수 없는 점을 거부·유지·직선거리 대체하는 세 정책, 미사용 점, 중복·잘못된 시드, 비유한 값 및 점·코너·시드·간선·큐·가중치 예산의 실패를 검사했다. 실패 시 기존 자료가 유지되는지도 확인했다.
- 본체 편집기의 undo·redo, 템플릿 레이어 활성화와 프로젝트 이력 복원 및 NSCharacter 참조 편집기의 동일 API를 검사했다. 가중치 변경은 기준 위치·법선·UV를 바꾸지 않으므로 보존된 원본 FBX 탄젠트의 유효성도 유지한다.
- 프로시저 인체 생성에서 표면 바인딩을 선택하여 해상도 32와 기본 해상도 96을 검사했다. 기존 방식과 같은 메시 연결을 유지하면서 가중치가 달라지고 정규화되는지, 기본 눈 메시와 52개 얼굴 모프가 남는지 확인했다. 잘못된 방법이나 예산 초과 시 새 에셋이 등록되지 않는지도 검사했다.
- CC0 MakeHuman 시료의 원본 점 19,158개와 관절 163개에서 모든 뼈의 중립 위치로 엔벌로프를 만들었다. 보이는 원본 점 13,380개를 바인딩했고 미사용 점 5,778개는 제외했다. 이 입력에서는 미도달·직선거리 대체가 없었다. 시드 비교 5,231,580회와 간선 방문 8,722,456회를 기록했다. 영향이 있는 한 관절을 0.2라디안 회전했을 때 최대 점 이동은 약 0.0358m였다. 이는 한 시료의 수치 결과이지 제작용 변형 품질 판단이 아니다.
- 독립 Python 파서는 같은 시료의 FBX에서 보이는 원본 점 13,380개, GLB에서 렌더 정점 14,517개와 163개 관절을 확인했다. 각 가시 점의 가중치 합과 최대 4개 영향, GLB 관절 인덱스·가중치 합을 검사했다.
- 일반 구성의 선별 회귀 97개와 기본 해상도 생성 추가 검사, NSCharacter를 끈 코어 전용 구성의 62개, AddressSanitizer·UndefinedBehaviorSanitizer 구성의 관련 검사 12개가 통과했다. 묶음에는 중복이 있다. macOS 계측에서 누수 검출은 활성화하지 않았다.
- 별도 `build/` 스테이징 설치본을 참조한 코어 단독·선택형 이미지 코덱·NSCharacter C++23 소비자 3개가 통과했다. 사용자 `~/.local` 설치본은 변경하지 않았다. 검사한 일반·코어 공유 라이브러리의 동적 의존성에는 Qt가 없다.

시드 선택은 뼈 선분과 메시 간선의 근사이며 체적 geodesic, 임의 스캔의 자동 관절 추론, 제작용 의상·얼굴·손 변형의 완성된 해법이 아니다. 사용자 지시에 따라 CC5·Blender·Unreal을 실행하지 않았고, Windows·Linux와 실제 앱에서의 가져오기·시각 품질도 확인하지 않았다.
