# 자동 골격 규칙 판별 검증 기록

## 범위

이번 변경은 [휴머노이드 본 대응](HumanoidCharacterization.md)의 내장 골격 규칙 판별과 기존 이름 변경·기준 자세 계획의 연결을 다룬다. 실제 본 이름과 부모 계층을 검사하고 각 후보의 부분 대응과 거부 이유를 제공한다. 완전한 후보가 여럿이면 모든 역할의 본 ID까지 비교하며, 대응이 다른 경우에는 자동 선택하지 않는다. 프로시저·Unreal 규칙의 동일 대응은 출처 식별 없이 공통 대응만 제공한다.

판별 결과는 작은 메타데이터와 본체 에셋에 대한 만료 가능한 참조이다. 메시·본·스킨·리그와 편집 이력의 소유자는 `Object3DEngine`이다. 이 기능은 제어 리그를 생성하지 않으며, 근거가 없는 이름 공간 변환과 의미 태그를 이용한 출처 추정도 수행하지 않는다.

## 검사 대상

- 합성 CC5 G5, Blender 메타리그와 밑줄 변형 골격: FBX와 GLB를 각각 SDK로 출력하고 다시 읽어 정확한 이름·역할·부모 관계를 판별한다. 결과를 G3 이름 계획과 편집 이력에 연결한다.
- 합성 G3 골격과 SDK 프로시저 골격: G3의 단일 후보와 프로시저·Unreal의 동일 대응 후보를 확인한다. 호출자가 명시적으로 후보를 제한하는 경우도 검사한다.
- 같은 에셋에 충돌하는 두 골격, 필수 본 누락, 잘못된 부모 계층, 다른 규칙을 흉내 내는 의미 태그, 중복·알 수 없는 후보, 규칙·부모 방문 예산, 엔진 소멸 뒤 참조 만료를 검사한다.
- `resources/rig-sampling/`의 CC0 성인·아동 FBX를 SDK로 읽고 MakeHuman 규칙과 기준 자세 계획을 확인한다. 이 자료는 실제 앱 동작 시험이 아니다.
- NSCharacter 포함 설치 소비자는 공개 헤더와 라이브러리의 판별·후보 제한을 사용하고, 본체 전용 소비자는 NSCharacter 없이 빌드한다. 테스트 설치 위치는 프로젝트 `build/`이며 사용자의 설치본을 변경하지 않는다.

## 실행 결과

macOS arm64에서 C++23 Release 구성의 본체 전용 회귀 검사는 56/56, NSCharacter 포함 골격·자세 관련 선별 검사는 44/44 통과하였다. 이후 공개 후보 객체의 기본 enum 초기값을 추가하고, 최종 소스의 관련 골격 규칙 검사 18/18을 다시 통과하였다. DNA 지원을 켠 Release 빌드의 자동 판별 선별 검사 4/4도 통과하였다. 별도의 최종 Debug ASan·UBSan 선별 검사는 12/12 통과하였다. 설치 소비자는 본체 전용과 NSCharacter 포함 구성이 각각 1/1 통과하였다. 모두 애플리케이션 실행 검증 옵션이 꺼진 구성이다. ASan 검사는 누수 검출을 비활성화한 메모리·정의되지 않은 동작 검사이다.

테스트 기록은 `build/core-tangent-ninja/convention-core-regression.xml`, `build/glb-import-ninja/convention-detection-regression.xml`, 최종 `build/glb-import-ninja/convention-detection-final.xml`, `build/convention-detection-dna.xml`, `build/glb-import-full-asan/convention-detection-final.xml`과 두 설치 소비자의 `convention-consumer.xml`이다. 설치한 공개 헤더는 소스와 일치하며, 포함 구성 라이브러리의 직접 링크는 시스템 C++ 런타임과 시스템 라이브러리이다. 빌드 결과와 별도 설치 검사에 Qt를 연결하지 않았다.

## 제약

판별은 명시된 15개 몸 역할을 포함하는 이름·계층의 일치만 확인한다. 실제 앱에서 가져오기, T 포즈와 제작용 컨트롤 리그, 모든 골격 변종, MetaHuman 품질은 검증하지 않았다. FBX 점진 모프는 기존처럼 명시적으로 거부하며, 이 작업에서 중간 형상·제어값·애니메이션의 보존이나 재출력을 구현하지 않았다. 프로젝트 전체 목표에는 제작용 얼굴·몸·의상 품질 및 상호 교환의 추가 구현이 남아 있다.

사용자의 지시에 따라 CC5·Blender·Unreal, 그 밖의 애플리케이션 및 사용자용 명령행 실행 검증은 수행하지 않았다. C++ 자동 테스트와 독립 소비자만 사용한다.
