# 캐릭터 재질 표면 검증 기록 — 2026-10-29

이 기록은 `iiActorObject` 본체의 재질 표면 설정과 NSCharacter 위임을 다룬다. 전체 캐릭터 제작 기능이나 다른 앱과의 완전한 호환성을 검증한 보고서는 아니다.

## 확인한 동작

- GLB의 불투명·마스크·혼합 방식, 임계값, 양면 여부와 Opaque에서 무시되는 원본 알파 및 PNG 연결을 보존한다. 형식 바이트는 SDK 판독기와 별개로 검사했다.
- 편집기, 비파괴 템플릿 레이어, 레이어 강도, undo/redo, 외부 편집 충돌 처리와 프로젝트 버전 29 복원을 검사했다. 선택 이전 이력과 버전 29의 결합, 기존 버전 24의 탄젠트 보존도 확인했다.
- FBX의 표준 불투명도와 SDK 전용 재질 속성을 독립적으로 검사하고 SDK 재입력을 확인했다. 표준 불투명도만 외부에서 수정되어 보존용 정보가 낡으면 기본 가져오기가 실패하며, 작성용 정보 복원을 끈 호출은 표준 값을 사용하고 경고한다.
- macOS arm64에서 NSCharacter 포함 구성과 코어 전용 구성의 관련 네이티브·독립 형식 회귀 검사가 각각 77개 통과했다. 실제 앱 실행을 요구하는 검사는 제외했다.
- NSCharacter 포함 구성의 주소 및 미정의 동작 검사에서 관련 10개가 통과했다. 이 실행은 누수 검사 `detect_leaks=0`을 사용했다.
- `build/`의 분리된 두 설치 위치에서 각각 새 공개 헤더와 라이브러리를 소비해 재질 편집과 GLB·FBX·프로젝트 왕복을 확인했다. NSCharacter 포함 구성은 위임 호출도 검사했다. 두 라이브러리의 직접 연결 목록에 Qt가 없다.

## 한계와 후속 작업

- 이번 작업에서 CC5, Blender, Unreal 또는 다른 사용자 앱을 실행하지 않았다. 재질의 시각적 결과와 각 앱의 FBX 확장 보존, 실제 MetaHuman 제작 경로는 확인하지 않았다.
- FBX의 마스크·양면 설정은 SDK 전용 속성이므로 다른 앱이 같은 셰이더로 해석한다고 보장할 수 없다. DNA는 재질과 텍스처를 보존하는 경로가 아니며 호스트가 별도로 연결한다.
- 헤더의 재질 구조 크기가 바뀌어 기존 C++ 바이너리는 새 헤더와 라이브러리로 다시 빌드해야 한다. 별도 설치 검사만 수행했으며 `~/.local`의 사용자 설치본은 교체하지 않았다.
- 피부 산란, 머리카락 전용 셰이더, 다른 운영체제와 실제 제작 데이터, CC5·Blender·Unreal의 전체 메시·리그 생성 및 상세 편집은 이 기록의 완료 범위가 아니다.
