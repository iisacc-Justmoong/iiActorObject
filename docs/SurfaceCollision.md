# 공용 표면 거리와 닫힌 메시 충돌

## 소유와 질의

표면 질의 DTO·예산, `SurfaceCollider` 인터페이스와 `MeshCollider` 구현은 iiActorObject 본체에 둔다. 충돌체는 현재 형상의 불변 파생 스냅샷이며 원본 엔진·에셋·NSCharacter의 수명을 연장하지 않는다. 원본 형상이 바뀌면 새 스냅샷을 만든다.

기존 `MeshSurface::closest` 호출은 유지한다. 새 예산 인수와 `closestTriangle`은 점·삼각형 질의의 노드 방문·좁은 단계 삼각형 검사 수를 제한한다. 삼각형 쌍 질의는 정점/면·모서리/모서리·모서리/면 교차를 검사하므로 세 정점이 모두 외부에 있는 큰 면의 교차도 검출한다.

## 삼각형 쌍의 보수적인 사전 제외

최근접 거리의 상한이 유한할 때 두 삼각형을 임의 축에 투영한 구간의 간격을 사용한다. 반올림 오차를 바깥으로 확장한 투영 간격이 거리 상한과 축 길이의 상한보다 클 때만 정밀 쌍 계산을 생략한다. 이외에는 기존의 정점·변·면 계산을 그대로 수행한다. 질의 축을 먼저 사용하고 필요한 경우에만 후보 삼각형의 축을 계산하므로 삼각형별 캐시나 추가 메시 저장소를 만들지 않는다.

삼각형 작업 예산은 이 제외 판정보다 먼저 차감한다. ID·동률 우선순위·바리센트릭·위치·거리와 기존 예외 처리를 보존한다. 좌표 크기가 `1e100`보다 크거나 축을 정하는 삼각형의 변이 `1e-100`보다 작으면 해당 축의 사전 제외를 끈다. 아주 작은 변과 먼 좌표의 조합에서 원래 쌍 계산이 반환하는 overflow 오류를 사전 제외로 숨기지 않기 위한 조건이다. 비유한 투영도 기존 정밀 경로로 처리한다.

`MeshSurfaceProjectionTest`는 공간 인덱스의 결과를 삼각형 하나씩 무한 반경으로 질의한 독립 순회와 비교한다. 원본 ID와 미사용 점, 양쪽 면 방향, 여러 크기, 반경 경계·동률·필드 전체, 예산 차감 순서와 극단 좌표의 기존 예외를 확인한다. 이 회귀 검사는 2,688개 질의를 포함한다.

2026-10-27의 별도 직접 비교는 보관한 변경 전 소스와 실제 정본 SDK 공유 라이브러리를 사용하였다. 합성 질의 115,165개와 성인·아동 질의 30,720개의 결과 필드 전체·노드 방문·삼각형 횟수 및 검사한 예외가 일치하였다. 각 15,360개 인체 질의에서 성인은 0.676211초에서 0.247575초, 아동은 0.688185초에서 0.250020초로 관측되어 각각 약 2.73배·2.75배였다. 병행 작업 중 번갈아 실행한 해당 질의 구간의 측정이며 전체 편집·대형 프로젝트 재생 시간이나 사용자 체감 지연의 측정치가 아니다. 추가 삼각형 저장소는 0바이트이다. 직접 비교의 소스·라이브러리 해시는 `build/projection-integration/CanonicalBenchmarkVerification.json`에 기록한다.

정본 4개 빌드 구성·설치 소비자와 보존한 v11·v10 대형 인체 프로젝트의 전체 재생도 통과하였다. 생성·편집·v12 저장·복원·리그 재연결을 유지하며 품질 지표와 점·노드·삼각형 횟수 전체가 각각의 기준값과 정확히 일치하였다. 해당 결과와 실제 Blender 가져오기는 [정본 검증 보고서](CharacterizationProjectionVerification-20261027.json)에 기록한다. 전체 NSCharacter 묶음의 재실행과 변경에 대한 선별 검사는 보고서에서 구분한다.

## 닫힌 경계와 부호

`MeshCollider`는 닫힌 2차원 다양체 경계를 입력으로 받는다. 미사용 점은 유지하고 경계·비다양체 모서리·끊긴 정점 fan·퇴화 면을 거부한다. 파생 충돌 법선의 방향을 일관되게 정리하고 연결 성분의 포함 깊이에 홀짝 채움을 적용한다. 중첩된 안쪽 경계는 공동의 경계이다. 서로 겹친 여러 고체를 합집합 장애물로 사용하려면 별도 충돌체로 전달한다.

정점은 인접 면의 각도 가중 법선, 모서리는 두 면의 법선 합, 면 내부는 면 법선을 사용하여 거리의 부호를 판정한다. 양수는 고체 밖이고 음수는 내부이다. 원본 렌더 법선이나 토폴로지를 수정하지 않는다. 입력 경계가 자기 교차하지 않는다는 조건이 필요하며 자기 교차를 자동으로 고치는 기능은 아니다.

경계 위의 최근접점 계산에는 부동소수점 반올림 오차가 남을 수 있다. 거리 크기가 좌표와 해당 삼각형 크기의 표현 오차 수준이면 위치 차이를 단위화하지 않고 의사 법선을 기울기로 사용한다. 미세한 접선 방향 오차가 큰 접선 이동으로 바뀌는 것을 방지한다. 이 처리는 거리의 크기·원본 연결·원본 법선을 변경하지 않는다. `boundary_gradient` 회귀 검사는 좁고 긴 닫힌 상자의 경계에서 일관된 바깥 기울기를 확인한다.

방법의 근거는 [Bærentzen·Aanæs의 각도 가중 의사 법선 연구](https://orbit.dtu.dk/en/publications/signed-distance-computation-using-the-angle-weighted-pseudonormal/)이다. 논문의 문장·그림·구현 코드를 배포하지 않으며 수학적 정의를 별도 C++23 코드로 구현한다.

`fromMesh`는 작성용 제어점·표시 삼각형을 사용한다. 작성용 토폴로지가 없는 렌더 입력에는 선택적으로 정확히 같은 위치의 경계를 용접한 파생 충돌 형상을 사용한다. 근접하지만 다른 위치는 자동으로 합치지 않는다. 조회의 원본 삼각형 식별과 원본 에셋은 유지한다.

## 적용 범위

충돌 좌표는 동일한 오브젝트 좌표계이다. 실행 중의 골격 포즈를 자동으로 가져오거나 렌더 메시를 변형하는 객체가 아니다. 현재 변형된 위치로 충돌체를 만들거나 명시적인 [표면 맞춤](SurfaceFitting.md)에 전달한다. 실제 CC5·Unreal·MetaHuman 검증은 별도 완료 조건이다.
