# 기준 메시 법선의 상세 편집

## 소유권과 대상

기준 표면의 법선은 본체 `Object3DAsset`이 소유한다. 작성용 메시에서는 `MeshTopology::normals`와 불변 layout의 법선 ID를 사용하고, 작성용 토폴로지가 없는 메시에서는 렌더 정점의 법선을 사용한다. NSCharacter는 본체 편집기와 에셋을 참조한다. 여기서 다루는 법선은 [모프별 법선 델타](MorphNormals.md)와 별도이며, [노멀 맵 이미지](NormalMaps.md)도 아니다.

## 외부 편집 병합

`applyObject3DExternalEdits`는 기준·편집 스냅샷의 코너를 원본 layout ID로 대응하고, 기준 법선에서 편집 법선으로 가는 최단 회전을 정본의 현재 법선에 적용한다. 위치도 바뀐 경우에는 각 스냅샷의 기하 법선을 계산하여 표면 변화에 따른 법선 방향과 수동 법선 차이를 구분한다. 현재 정본의 기하 법선에 대해 기존 법선 방향을 전달한 뒤 외부 편집의 회전 차이를 적용한다. 현재 정본이 외부 편집을 시작할 때의 정본과 같다면 그 결과는 편집 파일의 법선 방향과 일치한다.

외부 기준 파일에서 공유 법선이 이미 서로 다르게 분리되어 있더라도 편집 파일이 이를 바꾸지 않았다면 법선 수정으로 취급하지 않는다. 실제 방향 편집을 반영할 때 같은 원본 법선 ID를 공유하는 코너는 같은 결과를 요구해야 한다. 서로 다른 방향으로 나누는 수정이나 법선 ID가 없는 원본에 새 법선을 만드는 수정은 별도의 작성용 토폴로지 변경이 필요하므로 거부한다. 외부의 법선 방향 편집이 감지되었는데 기준 법선이 정본과 허용 오차 밖으로 다르거나 법선의 존재 여부가 바뀌면 실패하며 원본은 변경되지 않는다. 외부 앱이 재출력한 원본 ID 대응은 기존 [외부 편집 계약](ExternalEdits.md)을 따른다.

`Object3DExternalReport::normals`는 새로 적용된 기준 법선 ID의 수이다. 위치 이동만으로 생긴 법선 재계산과 구분한다. 호출자는 `positionTolerance`, `attributeTolerance`, `referenceTolerance`를 지정할 수 있다. 법선은 방향으로 정규화하며 0 벡터와 유효하지 않은 수치는 거부한다. 서로 정확히 반대 방향일 때의 회전축은 결정적으로 선택한다. 공개 보고서 구조가 바뀌었으므로 C++ 소비자는 일치하는 헤더와 라이브러리로 다시 빌드해야 한다.

## 비파괴 계층과 저장

템플릿 편집기는 기준 법선 보정을 원본 법선 ID와 회전으로 기록한다. 표면 위치와 자동 맞춤, 관절을 계산하고 기하 법선을 갱신한 뒤 활성 법선 보정을 계층 순서대로 적용한다. 계층 강도는 회전을 항등 회전에서 보간한다. 정점 마스크는 같은 법선 ID를 참조하는 **서로 다른 원본 점**의 가중치 평균을 사용하므로 공유 법선을 코너마다 다른 값으로 갈라놓지 않는다. 렌더 메시에서는 해당 정점의 가중치를 사용한다. 법선 보정과 모프 법선은 각각 유지한다.

일반 `Object3DEditor::replace`의 법선 수정과 외부 편집은 undo·redo, 레이어 교체와 프로젝트 저장을 사용한다. 정점 위치와 법선을 함께 반영할 때는 기존 계층을 포함하여 예상 결과를 계산하고 필요한 법선 회전만 새 계층에 기록한다. 저장된 이력에 법선 보정이 하나라도 있으면 `.ii3dproject` 버전 19 이상을 쓴다. 이전 버전을 계속 읽으며 법선 보정이 없는 프로젝트는 기존 버전 선택을 유지한다. 복원 시 중복·범위 밖 ID와 비정규 회전을 검사한다.

## 범위

이 기능은 원본 토폴로지의 법선 ID를 변경하지 않는다. 새로운 hard edge나 법선 seam을 만들려면 토폴로지 편집이 필요하다. 앱의 법선 재계산·재출력 정책, 탄젠트·노멀 맵과의 시각적 일치는 독립 문제이다. 현재 CC5·Blender·Unreal과 사용자용 앱은 실행하지 않는다.
