# 자동 관절 투영과 템플릿 형상 추정 검증

2026-10-28 macOS arm64에서 [자동 관절 앵커 투영](TemplateRigProjection.md)과 [표면 기반 형상 추정](TemplateShapeFit.md)을 네이티브 수치 및 독립 형식 파서로 검사했다. 실제 CC5·Blender·Unreal을 실행하지 않았으며, 결과를 앱 호환이나 제작용 외형 검증으로 해석하지 않는다.

- 서로 다른 삼각분할의 합성 메시에서 기준·대상 표면을 통해 관절 앵커와 스킨을 자동 생성했다. 표면 아래 0.2 단위의 숨김 보조점이 표면 오프셋을 유지하는지, 기울어진 대상 표면에서 최근접점에 맞춰 이동하는지, 원본 점의 반복 사용을 한 번만 질의하는지 확인했다. 거리·법선 방향·vertex·triangle·점·BVH 작업 예산, 잘못된 설정과 명시적 앵커 혼합을 거부하며 실패 시 에셋 목록이 유지된다.
- 축별 경계 정렬은 평면의 0 두께 축을 무리하게 스케일하지 않고 이동만 적용한다. 비유한 설정, 축 배율 범위 초과와 퇴화 입력은 거부한다. 형상 추정의 빈 후보·중복·잘못된 후보, 비유한 설정과 작업 예산도 검사한다. 평가 한도에 도달한 부분 결과는 `converged=false`로 표시한다.
- 공개 CC0 인체의 표면을 재분할하여 렌더 정점 14,517개를 41,273개로 늘렸다. 대상 앵커를 지정하지 않고 기준의 1,117개 고유 앵커 점을 투영해 관절 163개를 계산했다. 동일한 표면에서 관절 위치 최대 오차는 약 `6.8e-16`, 기존 정점의 스킨 가중치 최대 차이는 약 `2.2e-16`, 한 관절을 0.2라디안 회전한 변형 위치 최대 차이는 약 `9.0e-16`이었다. 관절 회전 전후의 최대 이동은 약 `0.0331` 오브젝트 단위였다.
- 같은 인체에 축별 `1.03·1.01·1.02` 배율과 이동을 준 시료에서 정렬 없이 가까운 표면만 사용하면 최대 관절 오차가 약 `0.0321`, 평균 스킨 차이가 약 `0.203`이었다. 축 경계 정렬을 적용하면 이 **전역 축별 변환 시료**의 관절과 스킨 차이는 수치 오차 수준이었다. 일반적인 국소 변형이나 포즈에도 같은 성능을 뜻하지 않는다.
- 별도 시료에는 상다리 길이 타깃 0.5와 코 세로 타깃 0.4를 적용했다. 형상 추정 없이 축 경계만 정렬하면 최대 관절 오차가 약 `0.0255`, 평균 스킨 차이가 약 `0.253`이었다. 두 후보를 미리 알려 주고 추정하면 최대 관절 오차는 약 `1.1e-6`, 평균 스킨 차이는 약 `1.0e-6`이었다. 후보를 비워 전체 472개 타깃을 탐색한 동일 시료에서도 두 타깃을 선택해 17회 수락·137회 평가 후 같은 수치 결과에 도달했다. 표면 평균 제곱 거리는 약 `2.11e-4`에서 `9.55e-15`로 감소했다. 알려진 두 변형의 한 시료이며 임의 스캔이나 모든 인체 변형에 대한 일반화 근거가 아니다.
- 대상 형상 파라미터가 이미 알려진 경로는 `referenceValues`로 별도 에셋 등록 없이 스냅샷을 평가한다. 원본 작성 점과 렌더 캐시가 생성 에셋과 일치하는지 검사했고 같은 국소 변형의 최대 관절 오차 약 `8.1e-16`, 최대 스킨 차이 약 `2.2e-16`을 확인했다. 기준 형상 데이터나 미사용 원본 ID는 변경하지 않는다.
- 독립 Python 파서가 재분할 결과의 FBX 원본 점 41,273개와 GLB 정점 41,273개에 대해 관절 인덱스·모든 스킨 영향·가중치 합을 검사했다. 각 앱의 가져오기나 렌더링 검사는 아니다.

최종 소스로 일반 구성과 NSCharacter를 제외한 코어 구성을 각각 빌드했다. 리그 전사 전용 검사는 일반 10/10, 코어 6/6이 통과했고, 관련 템플릿·스킨·스켈레톤·프로젝트·FBX 회귀 검사는 일반 96/96, 코어 95/95가 통과했다. 코어 회귀 검사에는 전사 전용 6건이 포함된다. 별도 설치 스테이징에서 NSCharacter 소비자와 두 코어 소비자 검사도 각각 1/1 통과했다. AddressSanitizer와 UndefinedBehaviorSanitizer를 적용한 리그 전사 검사는 실제 인체 시료를 포함해 7/7 통과했다. macOS에서 누수 검출은 비활성화했다. 일반·코어 공유 라이브러리의 동적 의존성은 C++ 표준 라이브러리와 시스템 라이브러리이며 Qt는 포함되지 않는다. 설치본은 `build/` 아래에서만 검증했다.

투영은 비강체 등록이나 인체 의미 인식이 아니다. 가까운 다른 부위가 선택되거나, 비슷한 표면을 만드는 서로 다른 타깃의 내부 관절이 달라질 수 있다. 거리·법선·수렴 검사를 통과해도 오차를 전부 탐지하지 못한다. 다른 자세·의상·부분 스캔·얼굴과 손의 제작용 품질, DNA와 실제 앱의 동작은 남아 있다.
