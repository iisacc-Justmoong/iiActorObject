# 계산된 표면 위의 상세 편집 계층

## 해결하는 문제

자동 맞춤 전 의상의 점이 `z=0.999m`, 맞춤 후 화면에 보이는 점이 `1.002m`인 예에서 바깥쪽으로 `0.01m` 이동하면 결과는 `1.012m`이어야 한다. 이전 계층은 이동량을 맞춤 전 점에 더하여 `1.009m`를 만들었다. 제약을 만족하더라도 사용자가 지정한 상세 편집을 보존하지 못하는 경우이다. 본체 조형과 외부 FBX 편집 병합에서 같은 문제를 재현하였다.

## 본체 소유 평가 경계

`Object3DEditLayerInfo::evaluation`은 본체 계층의 평가 방법이다.

| 값 | 계약 |
| --- | --- |
| `Object3DLayerEvaluation::Deferred` | 기존 방식으로 보정을 누적한 뒤 표면 추종과 자동 맞춤을 계산한다. 이전 프로젝트와 자동 맞춤이 없는 편집의 기본값이다. |
| `Object3DLayerEvaluation::EvaluatedSurface` | 이 계층 앞의 표면 추종과 자동 맞춤을 먼저 계산한 뒤 보정을 적용한다. 활성 자동 맞춤이 있는 상태에서 새로 만든 상세 편집에 사용한다. |

평가 중인 메시·편집 상태·설정·이력은 iiActorObject 본체에 있다. NSCharacter의 편집기는 본체 세션을 호출하고 계층 정보를 조회한다. 별도의 버퍼나 엔진 소유권을 갖지 않는다.

본체는 다음 순서를 사용한다.

1. 템플릿 파라미터에서 원본 형상을 계산한다.
2. 활성 계층을 순서대로 적용한다. `EvaluatedSurface` 계층 앞에서는 앞선 위치 편집의 표면 추종과 자동 맞춤을 마친다.
3. 각 표면 평가의 최종 형상을 다음 표면 추종의 기준으로 사용하여 이전 추종·맞춤 변위를 다시 더하지 않는다.
4. 마지막 위치 편집의 추종과 맞춤을 완료한다. 위치가 변하지 않은 상태에서 동일한 평가를 반복하지 않는다.
5. 최종 형상으로 관절 앵커를 계산하고 수동 관절 보정·파생 법선을 적용한다.

비활성 계층과 강도 0인 계층은 평가 경계를 만들지 않는다. 계층의 강도와 점 마스크는 저장한 사용자 보정에 적용한다. 맞춤 결과를 보정 델타에 굳혀 넣지 않으므로 자동 맞춤을 해제하면 그 자동 보정만 사라진다.

표면 제약은 각 평가에서 그대로 사용한다. 고정점·이동 한도·질의 예산 때문에 만족할 수 없으면 전체 편집이 실패하며 기존 스냅샷·revision·계층·이력을 유지한다. 평가 순서는 결과에 영향을 준다. 예를 들어 안쪽으로 눌렀다가 맞춘 뒤 바깥쪽으로 이동하는 두 계층은 반대 순서와 같은 결과를 요구하지 않는다.

## 외부 편집과 이력

외부 앱의 기준/편집 파일 차이는 현재 계산된 본체 형상에 반영한다. 평가 계층을 만들 때 의상·부착물의 표면 추종을 역산하는 기준도 해당 계층 앞의 계산된 형상이다. 몸이나 의상을 외부에서 편집한 후 부착물의 절대 위치를 유지한 경우 그 추종 변위를 중복 적용하지 않는다.

`replaceLayer`는 기존 계층의 ID·순서·강도·점 마스크를 유지하면서 현재 규칙에 맞는 평가 방법과 보정을 다시 기록한다. 동일 외부 편집을 반복 반영하여 이동량을 누적하지 않는다. 기존 계층의 평가 방법을 일반 조회 API로 임의 변경하지 않는다.

## 프로젝트 버전과 이전 자료

보존 이력에 `EvaluatedSurface` 계층이 있으면 프로젝트 버전 10을 작성한다. 평가 계층 없이 맞춤 규칙만 있으면 버전 9, 둘 다 없으면 버전 8을 작성한다. 입력은 버전 1~10을 읽는다. 버전 10의 계층 metadata에는 평가 종류의 정수 값이 추가되며 알려지지 않은 값은 거부한다.

버전 1~9에서 읽은 계층은 `Deferred`이다. 이전에 저장한 스냅샷과 이력을 다른 의미로 재해석하지 않는다. 이후 활성 맞춤 아래에서 새로 생성한 편집 계층은 새 평가 방법을 사용한다. 외부 편집의 명시적인 교체는 현재 기준 파일의 의도를 다시 계산한다.

이전 구현으로 작성한 두 버전 9 fixture를 별도로 보존하였다. 두 번째 파일은 화면상의 `0.01m` 이동이 기존 방식에서 `1.009m`가 되는 문제의 이전 의미도 보존하는 회귀 자료이다.

| 파일 | 바이트 | SHA-256 |
| --- | ---: | --- |
| `tests/fixtures/project/v9.ii3dproject` | 5775 | `1ea7ec7525a6b31905edf97f8e38ed3a160b919257345ca5dc428ae6ab714d35` |
| `tests/fixtures/project/v9-evaluated-surface.ii3dproject` | 7105 | `36f1faed8f0db2edf740c0e967e309121124d4d5ff06f1a558ea57fec93ca9b6` |

## 검증과 범위

수치 회귀는 실제 이동량, 반복 조형, 파라미터 변경 후의 간격, 계층 순서·강도·마스크·해제, 표면 추종 체인, 외부 편집의 절대 부착물 위치, 반복 교체, 실패 원자성, 버전 9 의미와 버전 10 저장 복원을 검사한다. 별도 Python 검사는 CRC를 검증하고 올바른 CRC를 가진 잘못된 평가 종류도 입력하여 복원 실패와 기존 엔진 보존을 확인한다.

이 변경은 상세 편집의 의도를 비선형 맞춤과 함께 보존하는 계산 경계이다. 제작용 의상 토폴로지·곡률·동적 천·자기 충돌·포즈별 보정과 전체 MetaHuman 품질을 대신하지 않는다. 실제 CC5·Unreal 적용은 별도 앱 검증이 필요하다.

실제 Blender 4.5.9 LTS에서는 자동 맞춤 인체의 5개 메시·163개 본을 불러와 의상 제어점 하나를 3mm 이동하고 정점 순서를 뒤집었다. 본체 병합에서 반복 교체·강도·점 마스크·체형 변경·저장 복원·얼굴 리그 재연결을 검사한다. 최종 FBX를 다시 불러와 기준 점 좌표, 메시별 59개 또는 60개 모프, 5mm 루트 스킨 이동, `pose/JawDrop`의 실제 표면 변형을 확인한다. 포즈 상태의 의상 충돌 제거를 증명하는 검사는 아니다.
