# 자동 자세 보정 검증 기록 — 2026-10-29

이 기록은 [자동 자세 보정](AutomaticCorrectives.md)의 이번 소스 상태에 대한 근거다. 본체 엔진이 원본과 새 3D 에셋을 소유하고 NSCharacter가 인체 역할 규칙과 비소유 참조를 제공하는 구조를 유지했다.

## 확인 범위

- 코어 전용 구성에서 자동 보정·기존 자세 보정·애니메이션 베이크·듀얼 쿼터니언 스키닝 관련 32개 테스트가 통과했다.
- NSCharacter를 포함한 구성에서 같은 범위와 인체 자동 계획을 합한 40개 테스트가 통과했다. CC0 인체의 19,000개 이상 원본 점과 150개 이상 본을 사용한 수치 비교가 포함된다.
- AddressSanitizer와 UndefinedBehaviorSanitizer 구성에서 자동 보정 관련 12개 테스트가 통과했다. 이 실행은 `ASAN_OPTIONS=detect_leaks=0`으로 누수 검사를 끈 상태다.
- `build/` 아래에 각각 설치한 코어 전용 패키지와 인체 모듈 포함 패키지에서 새 공개 API를 사용하는 소비자 테스트가 각각 통과했다. 사용자 설치 위치 `~/.local`은 갱신하지 않았다.
- 별도 GLB 판독기가 스킨, 기존 모프, 생성 모프의 희소 접근자를 읽고 계산 결과를 독립 DQ 계산과 비교했다. 기존 프로젝트 저장·복원도 테스트했다.
- 생성된 macOS 공유 라이브러리의 직접 동적 의존성은 C++ 표준 라이브러리와 시스템 라이브러리이며 Qt 동적 의존성은 관찰되지 않았다.

실제 기본 모프값과 샘플용으로 명시한 모프값이 다를 때도 기본 자세의 유효하지 않은 법선을 거부하는 회귀 검사가 포함된다. 특이한 역변환은 기본적으로 거부하며, 명시적인 생략 정책의 결과와 잔차도 확인했다.

단순 시험 메시의 팔꿈치를 0~1.2라디안에서 25개 자세로 비교했을 때 최대 위치 차이는 단일 샘플 0.0383317, 세 샘플 0.0180774였다. 단위는 시험 메시의 좌표 단위다. 특정 메시·관절·모프 조건의 결과이며 다른 캐릭터나 자세에서도 같은 비율로 개선된다는 보장은 없다. 세 샘플 계획으로 실제 크기의 CC0 인체를 생성하고 첫 샘플의 위치·법선을 원본 DQ와 비교했다.

## 해석의 한계

샘플 자세의 기하학적 DQ 근사를 검사했으며, 모든 관절 각도·모프 조합이나 해부학적 피부 접힘의 정확도를 증명하지 않는다. 인체 축 계획은 휴리스틱이다. GLB·FBX는 모프를 전달하지만 외부 호스트의 실시간 보정 드라이버는 별도로 연결해야 한다.

CC5, Blender, Unreal 및 기타 사용자 애플리케이션은 지시에 따라 실행하거나 검증하지 않았다. 따라서 이 기록은 해당 애플리케이션의 가져오기 성공, 제작용 MetaHuman 품질, 전체 캐릭터 생성·편집 목표의 완료를 뜻하지 않는다. Windows·Linux 실기기 검사와 제작용 외형·얼굴·리깅 작업도 남아 있다.
