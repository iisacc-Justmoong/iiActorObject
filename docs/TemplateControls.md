# 템플릿 의미 조절과 복합 드라이버

## 소유와 역할

조절 항목·곡선·희소 타깃 드라이버는 공용 `Object3DTemplateDefinition`에 보관하며 본체 엔진이 소유한다. NSCharacter의 인체 로더는 그래픽 자료의 의미를 이 정의로 옮긴다. 인체 계층에 계산 버퍼·숨은 엔진·별도 파라미터 이력을 두지 않는다.

`TemplateControl`은 이름·범위와 호스트 UI가 사용할 표시 이름·그룹을 정의한다. 값 `0`은 항상 중립 상태이다. 호스트는 같은 `TemplateValue` 배열로 원본 타깃과 조절 항목을 입력한다. `Object3DTemplate::resolveValues`는 이를 타깃 배열 순서의 실제 가중치로 계산한다.

## 계산

`TemplateControlKnot`의 입력 값은 엄격한 오름차순이다. 곡선은 조절 범위 전체를 덮으며 구간 사이에서 선형 보간한다. 외삽하지 않는다. 하나의 `TemplateTargetDriver`는 지정한 타깃과 스케일, 한 개 이상의 `TemplateControlFactor`를 가진다.

드라이버의 기여도는 `scale * (현재 곡선 값들의 곱 - 중립 곡선 값들의 곱)`이다. 여러 입력 축의 곱으로 텐서 보간 계수를 표현하면서, 모든 조절 값이 0이면 원본 중립 자료를 유지한다. 드라이버 기여도는 같은 타깃에 직접 입력한 가중치에 더한다. 최종 가중치가 타깃 범위를 넘으면 실패한다.

양방향 조절은 음수 방향 곡선 `(-1,1), (0,0), (1,0)`과 양수 방향 곡선 `(-1,0), (0,0), (1,1)`을 서로 다른 희소 타깃에 연결한다. 하나의 슬라이더로 축소·확대 또는 뒤·앞을 조절한다. 세 점 이상으로 응답 감도를 정의할 수도 있다.

이 계산은 항상 중립 소스에서 시작한다. 파라미터 변경 뒤에도 본체의 보정 레이어·점 마스크·의상 연결과 undo·redo를 다시 적용한다. 기본 법선과 관절 기준점 재계산은 기존 템플릿 계약을 따른다.

## 검증과 제한

조절 이름은 원본 타깃·다른 조절 이름과 겹칠 수 없다. 범위는 유한하며 0을 포함하고 `[-1e6,1e6]` 안에 있어야 한다. 한 템플릿의 조절과 드라이버는 각각 최대 4,096개이다. 같은 타깃에는 하나의 드라이버를 정의한다. 드라이버의 입력 축은 최대 8개, 축별 곡선 점은 2~64개이고 전체 곡선 점은 최대 1,048,576개이다. 스케일과 곡선 가중치의 절댓값은 최대 `1e6`이다.

알 수 없는 입력·중복 입력·비유한 값·범위 초과·불완전한 곡선과 중복 드라이버는 거부한다. 계산 실패 시 엔진에 결과를 게시하거나 편집 이력을 변경하지 않는다. 모델의 해부학적 타당성과 교차 파라미터의 외형 품질은 인체 자료와 별도로 검증해야 한다.

생성 시 각 입력 축의 곡선 최솟값·최댓값으로 드라이버 전체 영역의 가중치 범위도 검사한다. 같은 드라이버에서 입력 축이 중복되지 않으므로 이 곱의 구간 검사는 모든 조절 조합을 포함한다. 원본 타깃 직접 입력과 조절을 함께 더한 최종 범위는 각 실행에서 다시 검사한다.

## 인체 조절

CC0 인체 로더는 원본 `modeling_modifiers.json`과 실제 포함된 타깃 이름을 대조하여 양방향 조절을 만든다. 조절 이름은 `model/그룹/원본항목-음수방향-양수방향`이다. 단방향 항목과 의미 정의에 없는 잔여 타깃도 0~1 조절로 제공한다. 원본 타깃 이름과 ID는 유지한다.

현재 포함된 472개 희소 타깃은 양방향 조절 222개와 단방향 조절 28개, 총 250개 항목으로 전부 연결된다. 단방향 가운데 7개는 modifier의 명시된 항목이고 21개는 잔여 타깃이다. 모든 항목의 양 끝점 500개를 평가하고, 선택한 의미 조절과 원본 타깃 직접 입력이 같은 소스 위치를 생성하는지 확인한다. `MakeHumanTemplateOptions::semanticControls=false`로 이전 원본 타깃 전용 정의를 만들 수도 있다.

이 항목은 기존 선택 그래픽 자료의 체형·얼굴 상세 조절이다. 나이·성별·인구집단·체중을 함께 보간하는 전체 macrodetails 그래픽 자료와 제작용 MetaHuman 토폴로지의 완성을 뜻하지 않는다. 본체의 복합 드라이버는 해당 자료를 연결할 수 있는 계산 경계이다.

## 저장

자체 프로젝트 버전 5는 본체 템플릿의 조절·곡선·드라이버와 입력 값·편집 이력을 보존한다. 버전 1~4를 읽을 때는 조절·드라이버가 없는 기존 템플릿으로 복원한다. 원본 v4 fixture를 유지하여 이전 입력을 검증한다.

위 행렬은 699회의 성공한 테스트 실행이다. 정의·범위·구간 곡선·두 입력 축의 곱·직접 타깃과 조절의 합성·원자적 실패·편집 이력·프로젝트 저장·이전 버전 읽기를 포함한다. 인체의 500개 조절 끝점을 검사하였고, 선택한 의미 입력과 원본 입력의 소스 위치 차이는 0이었다.

Blender 4.5.9 LTS에서는 GLB의 표시 정점 14,517개와 FBX의 원본 정점 19,158개를 각각 C++ 출력 좌표와 대조하였다. 위치 최대 오차는 GLB `5.99e-7m`, FBX `5.16e-7m`이고, 본 위치 최대 오차는 각각 `6.61e-7m`, `2.91e-7m`이었다. 163개 본을 읽고 팔 회전에 따른 0.19m 이상의 표면 변형을 확인하였다. 이 검사는 두 형식에서 동일한 애니메이션 포즈가 재현되었음을 뜻하지 않는다.

`build/template-controls/review/ControlledHuman.png`를 직접 검토하였다. 조절된 몸체가 렌더되지만 눈의 별도 메시·구강·머리카락·피부 텍스처·제작용 재질은 없고 어깨·손목 등의 표면 품질도 추가 작업이 필요하다. CC5·Unreal 실행 검증과 제작용 MetaHuman 품질은 완료되지 않았다.

현재 프로젝트 버전과 이전 입력의 호환 범위는 [자체 프로젝트 형식](Object3DProject.md)을 따른다. 이미지 자원과 작성된 점 대응은 [얼굴 부속 문서](FaceAssets.md)를 따른다. 앞선 날짜별 보고서는 당시 소스의 검증 기록이다.

[매크로 형상 생성](HumanMorphology.md)은 나이·성별 형상·근육·질량·키·비율·그래픽 계열의 8개 축을 본체의 곡선 곱 드라이버로 연결한다. 매크로 자료 사용 시 총 820개 타깃과 258개 조절을 사용한다. 자체 프로젝트는 접지를 보존하며 현재 버전과 입력 호환 범위는 [프로젝트 형식 계약](Object3DProject.md)을 따른다. 앞의 날짜별 보고서는 해당 단계의 역사적 스냅샷이다.
