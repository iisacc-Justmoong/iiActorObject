# 리그 제어 샘플과 실행 정책 검증 기록 — 2026-10-27

## 구현 범위

본체 `Object3DEngine`이 소유한 일반 리그 또는 DNA 리그에서 기준 제어 상태와 여러 끝점을 독립적으로 평가하여, 관절·블렌드셰이프가 함께 반영된 새 모프와 출처를 본체 자산으로 만든다. 원본 리그는 평가하거나 수정하지 않는다. NSCharacter는 새 본체 자산의 참조만 가진다. 출처는 입력 제어, 원본 본의 로컬 자세, 블렌드셰이프와 애니메이티드 맵을 기록하며 실행 가능한 리그나 셰이더 연결은 아니다.

네이티브 프로젝트 v14, FBX의 SDK 메타데이터, GLB의 extras와 JSON 출처를 제공한다. FBX 중복 메타데이터·중복 필드·CRC 오류, 지나치게 큰 이름 목록, 잘못된 제어와 예산 초과는 거부한다. 여러 같은 이름의 원본 모프와 사용하지 않는 포인트·법선 레이아웃의 보존을 검사한다.

## 테스트와 실행 정책

- 현재 사용자 지시: 별도 애플리케이션·명령행 실행 검증은 명시적 요청이 없으면 하지 않는다. 자동 단위·통합 테스트는 계속한다. 기본 CMake 옵션 `IIACTOROBJECT_VALIDATE_APPLICATION_EXECUTION`은 OFF이다.
- 지시 변경 전 동일 C++ 구현에 대한 전체 네이티브 회귀는 공유 105개, NSCharacter 없는 코어 306개, DNA 없는 코어 281개가 통과하였다. 당시의 명령행 실행 검사 5개는 이 숫자에서 제외하였다. 원본 XML과 당시 소스 지문은 `build/rig-sampling/pre-no-execution-validation/Results.json`에 보관한다.
- 지시 변경 후 앱 실행을 제외한 공유 자동 테스트 13개와 ASan·UBSan 자동 테스트 8개가 통과하였다. UBSan 진단은 즉시 실패하도록 설정하였다. 공유·코어 전용·DNA 제외·안전성 구성의 실행 정책 및 리소스 링크·정리 검사는 각 1개씩 통과하였다.
- 이전 지침 당시 설치된 명령행 도구와 이동한 복사본이 실행된 기록은 별도 보존하였다. 새 리소스 링크·정리 절차를 추가한 뒤에는 그 도구를 실행하지 않았다. CC5·Blender·Unreal도 실행하지 않았다.
- 기존 실행 실험의 임시 디렉터리 11개를 정리했다. 기록과 본체 소스, 고정 리소스와 다른 작업의 자료는 보존했다. 정상·예외 종료 시 리소스 링크와 임시 디렉터리의 정리는 앱을 실행하지 않는 자동 테스트로 확인했다.

## 리소스와 대형 자료

`resources/MakeHuman*`의 기존 해시 목록에 있는 848개 파일이 일치했다. 원본 `data/`는 보존하고 CMake 입력과 설치는 `resources/`를 사용한다. 합성 DNA 입력은 `resources/fixtures/dna/independent.dna`이며 SHA-256은 `48318a9de7b3ca1020deb44d28cced561adc9e7e1e63d3c4f7dd487553d3046b`이다.

성인·아동 리소스 각각 163본·5메시·43,474 원본 포인트의 샘플 끝점이 원본 리그 계산과 일치했다. 별도의 CC0 템플릿 시험은 성인·아동의 59개 얼굴 제어에 대해 472개 메시별 비교를 수행했으며 최대 위치 오차는 약 `1.34e-15`, 최대 법선 오차는 약 `8.84e-16`이다. 이는 독립적인 테스트 자료에 대한 수치 근거이다.

## 남은 범위

제작용 MetaHuman DNA의 ML·RBF 경로와 대규모 자료, 전신·손가락 기준 프레임, 바인드 변경 후 모션 재타깃, 포즈에 따른 의상 보정과 피부·머리카락·의상의 최종 품질은 추가 작업이다. 기존의 오래된 예제 앱 실행 검사는 리소스 링크와 정리 계약으로 아직 전환되지 않아, 추후 명시적인 실행 검증 요청이 있을 때 이를 먼저 수정해야 한다. 이번 빌드와 테스트는 macOS arm64에서 수행했으며 Windows·Linux 실행은 확인하지 않았다. CC5·Blender·Unreal의 실제 앱 호환성이나 전체 MetaHuman 기능 완성을 주장하지 않는다.
